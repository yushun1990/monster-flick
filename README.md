# 霸王拧（暂名）

一部长篇武侠 / 江湖权谋 / 阴谋 / 群像小说的创作仓库。

> **当前状态：大纲尚未完成。** 现有内容记录的是人物、主旨、前史关系、世界矛盾与若干强候选方向，不是冻结骨架。卷数、事件顺序、门派、功法机制和结局细节都仍可推翻。

## 当前最稳定的东西

这不是“旧武战胜新武”的故事，也不是“一个英雄推翻邪恶组织”。

组织必须真的强、真的有效、真的让很多人得到好处；与此同时，最大的收益会集中在核心利益圈，大量普通人则像被强制做了一笔买卖：得到一些，也交出一些选择、健康、时间与人生方向，少数人甚至只剩被使用的价值。

小说真正要写的是几种坚定观念的碰撞：

- 刘承重把组织、天下与自身利益逐渐等同；
- 张之焘拒绝把具体的人抽象成“大局数字”；
- 范野追寻内心的公正，愿意承担责任，却不能接受替别人完成同意；
- 龙默相信共同体和秩序有必要，也愿意承担治理、协调与妥协；
- 徐辰不把“百姓”浪漫化，也不替所有人说话，他认识的是一个个具体的人。

结局不会由作者宣布一套正确制度。

## “霸王拧”

“霸王拧”可以是一种剑法 / 剑理，也可以逐渐扩大成一种斗争方式，但具体武学机制仍未冻结。

当前必须守住的一点：

> **霸王拧本身不是价值观。**

它解决的是“怎么斗、怎么改变交锋走势”，不负责决定一个人为什么拔剑、该为谁拔剑。

> **能拧，不等于知道该往哪儿拧。**

此前用“范野证明：未必”概括全书主旨的想法已经否决，不再使用。

## 当前开篇强候选

正文不再从范野少年成长顺叙。

当前最强方向是：**从范野真正离开宗门的那一天开始。**

可以极轻地碰一下名字：

> **城郭之外谓之野。范野生在城里。**

然后立刻进入故事，不解释“野”的全部含义。

少年范野、王月出三败、张之焘崛起、龙默与徐辰的旧关系都沉入前史，只在当前剧情需要重新解释人物时穿插。

> **回忆不是补背景，而是重新解释现在。**

这样现实乒乓原型只负责更深层的灵感来源，正文离宗后的事件链必须完全成为小说自己的世界。

## 当前人物名（暂定）

- **范野**
- **郴竹**
- **张之焘**
- **王月出**
- **刘承重**
- **龙默**
- **徐辰**

名字都有私人暗纹，但原则不变：

> **梗可以深埋，名字必须先是名字。**

现实彩蛋不能成为理解人物的前提，也不能为了露梗专门搭戏。

## 当前人物关系方向

- **张之焘**：生于野，后来入宗，不是少年成名，而是突然杀出的黑马；三胜王月出后登顶，最终本来就会离开、回到野。
- **王月出**：张出现前的宗门顶级天才；连续失败后被冷落，后来是范野主动选择他为师，范野的成功又替他重新赢回地位、资源与家庭稳定。
- **龙默**：与张之焘、徐辰同代，不是高一辈老宗师；曾被王月出压到怀疑自己，后来重新找到完整、稳定的道路，最终最适合处理刘承重倒下后的现实残局。
- **徐辰**：同代怪才，地方商武家族背景是强候选；能力、武功、办事、人脉都路子野，组织对他的评价可以是：**此人可用，不可大用。**
- **老医师 / 药师**：没有传奇性，只是医术好、与人为善、不按身份区别病人；张无名时就给他治伤，后来又成为范野长期医师与亦师亦友者。

## 创作原则

- 世界不是为主角搭建的舞台；范野不存在，各方也会继续行动。
- 新武 / 密功必须真的强。
- 范野必须拥有多个真实可选项；如果选择刘承重，他也能真正进入核心利益圈、飞黄腾达。
- 群众不能只有一种态度：拥护、获利、忍耐、退出、躺平、阳奉阴违、偷偷抵抗、公开反抗都应存在。
- 最终改变秩序不能只靠一个英雄，而应包含大量分散的“不再配合”。
- 范野不会因为最有良知、最能打就自动最会治理，也不会成为新宗主。
- 龙默负责收拾残局不等于龙默的制度是作者答案。
- 张之焘影响范野主要靠人生与带他看见真实人间，不靠讲道理。
- 老医师必须先作为一个人活着，后续受辱也不能只为主角回来报仇服务。
- 不用数值化境界、系统、穿越、血脉觉醒或临场加点。
- 故事可以慢，但不能空。
- 幽默顺带发生，一句话尽量同时干两件事。
- 现实乒乓、Dota 等只作为更早一层灵感，绝不继续规定正文剧情。

## 当前阶段

当前优先级不是继续堆大事件，而是：

1. 继续养活范野、张之焘、王月出、刘承重、郴竹；
2. 做实张之焘—王月出—龙默—徐辰这一代的前史关系；
3. 做实老医师；
4. 验证“范野离宗当天”的开篇；
5. 再设计离宗后第一条完全属于小说自己的现实冲突；
6. 只拆未来 10–15 章，滚动写、滚动复审。
