## 当前最稳定的作品原则

这不是“旧武打败新武”的故事，也不是“揭露邪功以后所有政治问题都有统一答案”。

宗门必须真的强、真的有效、真的让许多人获益；与此同时，资源、选择权、健康、人生方向和退出权会被不均匀地重新分配。

真正的问题是：

> **谁决定代价，谁拿走收益，谁有资格替别人同意？**

核心原则之一：

> **恩不能自动变成所有权。**

刘承重真正贪恋的是权力、占有和“不失去”；长生秘法只是把这套逻辑推到身体层面。

范野追求的更接近具体公正：愿意承担，也愿意牺牲，但不能接受别人替一个具体的人完成同意。

张之焘更直接：先看眼前这个人，再谈大局。

龙默相信秩序和长期治理确实必要，因此刘倒下以后，最适合收拾残局的不是范野，而是这种愿意承担现实治理的人。

## 《剑经》

《剑经》首先必须真的是一部剑学。

古代大剑师 **俞大千** 留下极朴素的剑术札记：持剑、距离、进退、出锋、收锋、观察、变化和修正。第一层真正适合儿童启蒙，因此剑宗后世大量刊刻。

别人七八岁“毕业”以后去学更高级的内功与剑气；张之焘因为穷，反而长期只有这一本到处可以买到的书。

他在游历、交剑、受伤和生死战以后反复重读，同样的话不断变深。

> **不是《剑经》造就张之焘，而是张之焘让世人重新知道，《剑经》里原来真有东西。**

江湖后来相信另有“真《剑经》”，当前 canon 倾向：**物质意义上的真本根本不存在。**

详细见 [`docs/SWORD_CLASSIC.md`](docs/SWORD_CLASSIC.md)。

## 范野与天下狩猎

正文强候选第一句：

> **城郭之外谓之野。范野生在城里。**

范野开篇已经是天下数一数二的绝顶高手。

他不是离宗后才升级；有人也许能胜他，但“胜”和“杀”是两回事。敌人越强、战斗越久，他越有机会理解并修正自己的剑。

离宗时他归还名剑、身份、资源与组织支持，不自废修为。

离宗以后没有默认主角佩剑：敌人的剑、断剑、木棍、树枝都能用。

> **他懂的是剑，不只是一把属于自己的剑。**

狩猎不是固定山谷围杀。范野一离开剑宗，仇家、大势力、剑痴、投机者和剑宗本身的算盘便沿道路、客栈、渡口、城镇和势力边界同时追上来。

详细见 [`docs/OUTLINE.md`](docs/OUTLINE.md) 与 Issue #7。

## 郴竹、逍遥峰与小师妹：当前版特别提醒

此前仓库长期存在一套已经废弃的“峨眉 / 外围未被选择者 / 少年只说一句挺聪明”版本。**该版本全部作废。**

当前：

- 郴竹是逍遥峰首席大弟子、前任峰主最倚重的人、现任小师妹最亲近的姐姐；
- 她的巨大执行权在前任峰主生前就已经长期形成，不是小师妹继位后突然获得；
- 小师妹也不是继位后才会治理：她继位前已经掌握大量宗门信息，拥有父亲留下的中心元老、自己笼络的班底和主动投奔者；
- 核心三山正式为：**逍遥峰（主峰）、南冥峰（老大）、北冥峰（老二）**；另有上一届老峰主留给小孙女的小山 **缥缈峰**；
- 南冥、北冥是具有真实自治基础的副峰，但祖制一直明确主峰最高、接受副峰纳贡并拥有重大征伐调配权；
- 小师妹上位后逐步以**逍遥右使**深入副峰现实治理，并以**逍遥公子**制度介入副峰未来继承格局；
- **与清净宗暗中秘密合作的是南冥峰，不是缥缈峰**；双方长期相互利用；
- 清净宗同时秘密渗透北冥峰，**北冥峰主老二对此完全不知情，也绝不可能容忍**；
- 小师妹掌握证据后没有借机除掉南冥峰主，而是把证据与征伐名分交给怒不可遏的北冥峰主；
- **不到半个月斩首清净宗宗主和核心集团的人，是北冥峰主老二亲自率队，不是郴竹**；
- 清净宗没有灭门，随后由老成持重、处处与人为善的嫡系后人继承宗主之位；
- 这一战是小师妹“攘外而服众”的关键前史，也给她后续把主峰最高权力进一步制度化提供了现实窗口；
- 郴竹是顶级老江湖，不擅长设计十层阴谋，不等于不聪明；她最强的是看穿事情的骨头；
- 小师妹在天下狩猎发生时已经是现任逍遥峰掌门，并真正坐稳南冥、北冥；
- 小师妹深层欲望不是“夺天下”，而是**让自己拥有的重要东西不要再消失**；她擅长把宗门做成不依赖某个人也能运行的制度，却无法把“家”也制度化；
- 小师妹最初要范野，至少有一个非常现实的动机：**她看中了一把宝刀**；
- 郴竹就是抓范野行动负责人，不是外围警戒；
- 她先拿到昏迷范野，随后通过特殊旧疤认出童年救命故人；
- 认出以后，她凭多年老江湖直觉判断：**小师妹那里对范野是个危险的地方**，因此不汇报；
- 郴竹此前已经隐约产生“也许可以出去”的念头，范野只是让门外变得真实；
- 小师妹对郴竹的依赖极深，甚至可以不健康。她明知范野未必有错，也可以故意让他真正倒霉；
- 小师妹后期不会以“让范野输”为目的反复下手；她真正想要的是**大师姐重新把自己和逍遥峰放回生活中心**；
- 她最先、也最擅长攻击的是郴竹与范野初期尚未成熟的**信任**：利用真实裂缝、控制信息出现的时机，而不是依赖假信、假情人之类低级误会；
- **小师妹不会输，但是赢不了**：她可以真的制造猜疑、隔阂，甚至成功把郴竹与范野拆散，但“范野离开郴竹”不等于“郴竹回到从前”；
- 因此她会在事实上成为两人感情的磨刀石——她是真想拆，却不断逼他们解决原本就存在的问题；
- 她最后放手不是因为范野智斗赢了她，也不是突然宽宏，而是终于确认：**即使彻底拆掉两人，也换不回过去那个大师姐。继续赢已经没有意义。**
- 她的私人红线：**范野可以倒霉，郴竹不能动。**

## 写作纪律

> **故事可以慢，但不能空。**

核心参考之一是冰临神下式的冷、密、狠与因果感，但重点不是堆古雅句子、金句、机锋或冷笑话。

- 少替人物解释自己；
- 聪明不能消除流血；
- 阴谋从交易、路线、调度、死人与后果里长出来；
- 女人不能因为感情线自动变软；
- 幽默只能来自人物和局势；
- **禁止满篇废话和自以为幽默。**

详细见 [`docs/STYLE_GUIDE.md`](docs/STYLE_GUIDE.md)。
