# 剑经

一部长篇武侠 / 江湖权谋 / 阴谋 / 群像小说的创作仓库。

> **当前状态：大纲尚未完成。** 现有内容记录的是人物、主旨、前史关系、世界矛盾与若干强候选方向，不是冻结骨架。卷数、事件顺序、门派、功法机制和结局细节都仍可推翻。

> 《霸王拧》已完成早期灵感阶段的任务，现降为历史工作代号。当前第一候选正式书名为 **《剑经》**。

## 当前最稳定的东西

这不是“旧武战胜新武”的故事，也不是“一个英雄揭露邪功、推翻邪恶组织”。

组织必须真的强、真的有效、真的让很多人得到好处；与此同时，最大的收益会集中在核心利益圈，大量普通人则像被强制做了一笔买卖：得到一些，也交出一些选择、健康、时间与人生方向，少数人甚至只剩被使用的价值。

小说真正要写的是几种坚定观念的碰撞：

- 刘承重贪恋权力、占有与不失去，最终把宗门、天下与自身利益逐渐等同；
- 张之焘拒绝把具体的人抽象成“大局数字”，也拒绝按组织可计算的方式活；
- 范野追寻内心的公正，愿意承担责任，却不能接受替别人完成同意；
- 龙默相信共同体和秩序有必要，也愿意承担治理、协调与妥协；
- 徐辰不把“百姓”浪漫化，他认识的是一个个具体的人和真实运行的社会毛细血管；
- 郴竹不是“被选择的人”，却会在别人忽略的位置看见整个局的另一面。

结局不会由作者宣布一套正确制度。

## 为什么叫《剑经》

《剑经》首先真的是书中一本剑谱。

古代大剑师 **俞大千** 留下一部极朴素的剑术札记：不讲强大内力，不讲炫目的剑气，也不按“第一式、第二式”整理，写的多是持剑、进退、距离、出锋、收锋、观察和应变。

因为第一层确实适合启蒙，剑宗后世把它印得到处都是。常见状态甚至可以是：

> 七岁读《剑经》，八岁开始练真正的宗门剑法，从此再也不翻。

俞大千没有强大弟子谱系，香火渐衰。随着剑宗正统越来越重视内功、剑气与可规模化培养的体系，后世甚至开始怀疑他是否真有传说中的剑术水平。

张之焘生于野、家贫、爱剑，却接触不到昂贵高阶剑谱。《剑经》便宜、到处都有，反而成为他能够长期拥有、反复读的一本书。

别人早早从《剑经》“毕业”，张因为穷，反而一直没有毕业。

> **不是《剑经》造就张之焘，而是张之焘让世人重新知道，《剑经》里原来真有东西。**

张后来来到剑宗，一部分动机正是想看看：究竟什么地方，曾经养出俞大千这样的人。

## 张之焘与剑宗的旧伤

张之焘进入剑宗后，不只是三败王月出，而是把整个剑宗原本已经翻涌的暗流搅了出来。

刘承重早已在秘密推进一套长生 / 新武计划。范野少年成长时的剑宗还没有后来那么坏；到张之焘进入宗门时，人才标准、资源集中、统一训练和权力控制已经开始变味。

张未必知道最深的秘法，却会不断追问具体的人为什么必须被牺牲、为什么医师说该停还要继续练、为什么一个宗门的规矩可以压过眼前的人。

强候选旧事：张曾一人杀入二流门派 **玄清宗**，只因二长老祸害一家贫民、导致孩子流离失所。二长老七剑而死，最后一剑具有极强的凌空下劈视觉；玄清宗掌门手握剑柄，却愣是没有拔出。

这件事为剑宗提供了极漂亮的公开理由：擅闯他宗、私杀长老、越过公议、破坏宗门秩序。真正更深的原因则是：张已经严重干扰刘承重多年推进的计划，也证明一个强到无法忽略的人可以完全不按刘的规则活。

张最终被标记为“异类”。剑宗随后逐渐放出一种极诱人的传言：张身上有俞大千失落的真正剑谱。传言真假并不重要。

不同人会因此看到完全不同的东西：

- 散修、剑痴、武痴与投机者看见“一步登天”；
- 中小门派看见一个无法贿赂、无法预测、随时可能落在头顶的危险人物，希望合力除掉，还能换剑宗一份情；
- 真正的大宗门未必在乎一本剑谱，他们更在乎 **张之焘本人**：若能结盟、借势或短暂庇护，原本稳定的势力差就可能被改写。

因此后来几大势力共同讨论诛张，既有堂堂正正的秩序理由，也有各自完全不同的算盘。

## 范野与张之焘

范野离开宗门时已经是天下数一数二的高手。

他从小打到大，战斗经验极其丰富，对剑早有自己的完整认识。一个高手也许能胜他，但“胜他”和“杀他”是两回事。

张之焘认可范野，也正因为范野已经是一个真正的顶尖剑客，并且仍然有继续理解的能力。

张离开前把自己对《剑经》、剑意和剑术的一些认识传给范野，但范野没有学成“张之焘的剑”；他的主要武力仍来自剑宗正统。

更深扎进范野心里的，是张让他真正看见文书之外的人。

## 半年前的裂痕

当前强候选前史：几年一次、几大势力共同处理重大江湖事务的会盟上，“共同诛杀张之焘”成为重要议题之一。

追杀需要真正够资格的领军人物。

范野最合适：够强、最熟悉张的剑，而且天下已经察觉两人关系不同寻常。

让范野领军，也是一场公开的忠诚测试：

> 你若真与张无私情，那就由你去杀。

范野拒绝。

这个拒绝让天下第一次公开看见剑宗与它最耀眼的新一代高手之间出现裂痕。随后半年关系持续恶化，直到范野离开。

## 离宗不是“两清”

范野可以归还：

- 宗门名剑与公产装备；
- 身份牌、职印与权限；
- 宅院、坐骑、俸禄、药物配额、情报与人员支持；
- 明确属于宗门秘密、约定不得外传的传承。

但他不能把二十多年已经长进身体里的修为、经验和自己悟出的剑还回去，也不应自废武功。

真正的矛盾不是设计一套完美的“两清仪式”，而是承认：

> **恩可以承认，却不能自动变成对一个人的永久所有权。**

离宗最终要付出的具体身体 / 现实代价仍待设计，但“自废修为”当前否决。

## 当前开篇：不是固定围杀点，而是天下狩猎

正文不从少年成长顺叙，也不从宗门大厅慢慢交代离职。

可以极轻地碰一下名字：

> **城郭之外谓之野。范野生在城里。**

然后范野已经走出剑宗，狩猎开始。

剑宗故意让“范野确已离宗、状态不佳”成为天下都能听见的消息，又推动另一层传言：**张之焘把那部失落真剑谱传给了范野。**

刘承重并不需要设置统一伏击地点。

他的算盘更简单也更狠：

- 范野过去的仇家会来杀；
- 各大势力会派蒙面精锐来抢活人；
- 大家不敢公开承认自己在抢剑宗前核心人物，因此天然彼此猜忌；
- 剑宗精锐只需远远跟着，等别人先消耗范野、再互相争抢；
- 最合适的时候突然下场，既杀范野灭口，也可能顺手重创其他势力的核心人物；
- 第二天谁都很难公开追责，因为谁也不愿解释自己为什么蒙面出现在那里。

因此开篇不再是“山谷埋伏”，而是一场会沿道路、渡口、城镇与势力边界不断移动的 **天下狩猎**。

## 龙默、徐辰与郴竹

龙默不能亲自出现在救援现场。那会把沉稳承担的龙默写成“龙头青”。

当前方向：龙默在剑宗内部制造极细微的偏差 / 缝隙；徐辰利用真实社会网络，让外部聪明人从马匹、药材、道路、调度、客栈、渡口等蛛丝马迹里自己推理出“这里不对”。秘密不能被一封信直接送出去。

两人的目标也不是替范野安排好救援，而是：

> **逼剑宗失去一直站在棋盘外坐收渔利的能力，提前下场，把水真正搅浑。**

具体办法仍待设计。

郴竹来自另一大势力，却不是这次行动最被信任 / 最被选择的核心执行者。她更可能只在外围警戒，甚至不知道真正目标是谁。

她与少年范野只有一次很轻的旧印象：她做了一个聪明的小决定，别人没注意，范野恰好看见，随口说了一句“挺聪明”。不是大恩，不是旧债。

多年后她认出重伤的范野，先有一个极简单的判断：

> **不能让他死。**

她无法靠二打一杀穿所有高手。她真正厉害的是在蒙面、多方争抢、信息残缺和剑宗不能公开身份的条件下不断临机修正，让每一方都误以为范野落进了另一方手里。

最后可以保留一小段真正的浴血突围，但那只是把已经被智慧撕开的缝走完，不是靠蛮力打赢整场局。

## 剑宗正统、新武与隐藏很深的长生秘法

剑宗正统必须真的强。王月出、范野都在这套体系里成长为天下最顶尖的剑客。

刘承重早就发现失传长生秘法，也早就被它吸引。他没有等张之焘、范野“逼他黑化”；真正的问题是这套秘法需要多年铺垫：稳定宗门、筛选候选人、试验、资源、医疗、保密，以及一套能把人的力量变得更容易向上流动的新武体系。

新武本身是真的好用：内力增长快、恢复快、突破快，并能进一步放大剑气。

深层代价则是修炼者逐渐被改造成高效率的资源加工器。工作术语暂称 **本元**：资源转化越多，表面提升越明显，深层不可逆损耗也越重。

刘不会蠢到让整代天骄集体短命。他会培养很多人、小幅抽取，把长期衰退混进伤病和个体差异；接近危险线的人退休养老、转任教职，少数已经几乎没有继续价值又难以解释的人则被派往真实的高风险秘密任务。

更重要的是，剑宗对“天才”的定义开始被偷换：

> 以前看谁真正会剑；后来越来越看谁能最高效地把资源转化成体系需要的力量。

两者有关，但绝不完全线性。

所以真正的剑道奇才可能资源不足，而高转化效率的人会被不断投入资源、不断赢，再由战绩证明“宗门没有选错”。

范野成长早期，剑宗风气还没有这么差；张之焘进入时，湖水已经快翻，张只是把暗流砸出了浪；范野离开后，一个巨大的威胁和比较标准消失，体系才会明显加速异化。

最重要的叙事纪律：

> **黑魔法是地基，不是门面。**

前台首先写权力、人才、恩义、资源、商路、地盘、战争和真实江湖。中层才逐步出现身体、训练、退休、药材和核心人物依赖的异常。很后面才真正揭开长生与抽取。

刘最想要的不是“吸”。

**吸只是技术。占有才是欲望。**

详细工作稿见 [`docs/LONGEVITY_METHOD.md`](docs/LONGEVITY_METHOD.md)。

## 外部天下必须一直向前跑

不能让正文长期围着剑宗内部秘密打转。

天下本来就在变化：商路、港口、药材、地盘、盟约、地方势力、其他大宗门自己的改革，都应该制造真正会发生的事件。

刘承重不必制造所有危机，他更擅长利用真实危机集中权力和资源。

范野在宗门时期也应一直有重要外部任务做，因此他看见的内部异常始终只是碎片。

可以记成一句创作原则：

> **外部天下负责横向把故事往前推；剑宗内部异常负责纵向往深处沉。**

现实竞技原型、Dota 动作等都只停留在创作灵感层；小说人物和事件必须独立成立。

## 当前阶段

当前优先级：

1. 做实张之焘被逐、玄清宗旧事、共讨张之焘大会与范野拒绝领军；
2. 做实“离宗不是两清”，确定范野究竟失去什么，但坚持不自废修为；
3. 把固定围杀改成移动狩猎，设计刘承重如何坐收渔利、龙默 / 徐辰如何逼剑宗提前下场；
4. 做实郴竹作为外围未被选择者，如何在信息混乱中真正把范野偷走；
5. 继续细化长生秘法，但保持其深藏，不能让它吞掉主旋律；
6. 建立至少一条真正独立于剑宗秘密的外部世界事件链；
7. 只拆未来 10–15 章，滚动写、滚动复审。
