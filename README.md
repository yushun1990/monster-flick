# 霸王拧（暂名）

一部长篇武侠 / 江湖权谋 / 阴谋 / 群像小说的创作仓库。

> **一句话核心**：一个早已站在旧武巅峰的天才高手，在整个江湖被“资源型武学”改写之后，以更低的账面实力重新归来。别人比他功力深、兵器强、人数多，但真正交手时——没人有把握拿下他；打得越久，越危险。

## 主旨

这不是“旧武战胜新武”的故事，也不是单纯的“个人英雄打倒邪恶组织”。

核心问题是：

> **一个人的天赋、努力、荣耀和生命，究竟属于自己，还是属于培养他的组织？**

组织可以培养人、保护人，但培养不等于拥有。

小说中的核心邪法最终吸取的不只是功力，还象征着对人的身体、青春、名声、服从、价值乃至人生选择权的占有。

因此全书最重要的主题是：

> **人的不可占有性。**

另一个主题是“真正的强大来自哪里”。新时代的灵药、秘法、神兵和组织资源都是真的强，小说不会靠“邪功根基虚浮”替主角作弊。主人公仍能抗衡，是因为他真正理解战斗：力量会耗尽，装备有上限，而真正的高手在战斗结束前没有固定上限。

## “霸王拧”

“霸王拧”最初可以是一招，也是一位前代传奇高手的武学观，最终成为全书的精神核心：

> **别人可以把你逼到只能防守的位置，但别人不能替你决定，你下一招是不是进攻。**

## 创作原则

- 世界不是为主角搭建的舞台；故事开始以前，它已经运行了很久。
- 不做“世界观说明书”，不给读者一次性解释所有机制。
- 不使用数值化境界、系统、穿越、血脉觉醒等捷径。
- 新武 / 密功必须真的强，否则时代变革不成立。
- 主角不靠隐藏神器或临场爆种获胜；他的核心优势是判断、适应、战斗本能和极扎实的基础。
- 所有重要对手都必须聪明，不靠降智制造爽点。
- 每个场景尽量同时承担两项以上功能：推进事件、改变关系、暴露人物、埋伏笔、补世界信息。
- **故事可以慢，但不能空。**
- 幽默来自事实、人物处境和一本正经的叙述，不靠无中生有的贫嘴。
- 感情线不承担“拯救”功能；男女主都必须拥有独立的人生、矛盾与选择。
- 结局不恢复一个完美世界；反派死亡后，天下仍然复杂。

## 当前阶段

项目处于 **P0：骨架冻结 / 小说宪法** 阶段。

当前优先事项不是继续增加大事件，而是：

1. 固化不可违反的创作原则；
2. 完成五名核心人物：范野、张继狂、王昊、刘玄功、陈昭月；
3. 让人物反过来修订大纲；
4. 再设计第一卷；
5. 最后只拆接下来 10–15 章，不提前把整部长篇机械化。
