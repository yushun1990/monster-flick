# 剑经

一部长篇武侠 / 江湖权谋 / 阴谋 / 群像小说的创作仓库。

> **当前状态：大纲尚未完成。** 现有内容记录的是人物、主旨、前史关系、世界矛盾与若干强候选方向，不是冻结骨架。卷数、事件顺序、门派、功法机制和结局细节都仍可推翻。

> 《霸王拧》已完成早期灵感阶段的任务，现降为历史工作代号。当前第一候选正式书名为 **《剑经》**。

## 当前最稳定的东西

这不是“旧武战胜新武”的故事，也不是“一个英雄推翻邪恶组织”。

组织必须真的强、真的有效、真的让很多人得到好处；与此同时，最大的收益会集中在核心利益圈，大量普通人则像被强制做了一笔买卖：得到一些，也交出一些选择、健康、时间与人生方向，少数人甚至只剩被使用的价值。

小说真正要写的是几种坚定观念的碰撞：

- 刘承重把组织、天下与自身利益逐渐等同；
- 张之焘拒绝把具体的人抽象成“大局数字”；
- 范野追寻内心的公正，愿意承担责任，却不能接受替别人完成同意；
- 龙默相信共同体和秩序有必要，也愿意承担治理、协调与妥协；
- 徐辰不把“百姓”浪漫化，也不替所有人说话，他认识的是一个个具体的人。

结局不会由作者宣布一套正确制度。

## 为什么叫《剑经》

《剑经》首先真的是书中一本剑谱。

古代大剑师 **俞大千** 留下一部极朴素的剑术札记：不讲强大内力，不讲炫目的剑气，也不按“第一式、第二式”整理，写的多是持剑、进退、距离、出锋、收锋、观察和应变。

因为第一层确实适合启蒙，剑宗后世把它印得到处都是。常见状态甚至可以是：

> 七岁读《剑经》，八岁开始练真正的宗门剑法，从此再也不翻。

俞大千没有强大弟子谱系，香火渐衰。随着剑宗正统越来越重视内功、剑气与可规模化培养的体系，后世甚至开始怀疑他是否真有传说中的剑术水平：若真是绝世剑师，怎么净写这些“小孩子都懂”的基础？

张之焘生于野、家贫、爱剑，却接触不到昂贵高阶剑谱。《剑经》便宜、到处都有，反而成为他能够长期拥有、反复读的一本书。

别人早早从《剑经》“毕业”，张因为穷，反而一直没有毕业。

他在真正的交锋、重伤与生死之间不断回头读，才逐渐从同样的句子里读出不同的剑意。

> **不是《剑经》造就张之焘，而是张之焘让世人重新知道，《剑经》里原来真有东西。**

张后来来到剑宗，一部分动机正是想看看：究竟什么地方，曾经养出俞大千这样的人。

## 剑宗正统与《剑经》

剑宗正统必须真的强。

王月出、范野都在这套体系里成长为天下最顶尖的剑客。当前武学方向是：以内力贯剑，使剑与气形成高度统一的振动 / 波动，高手可以形成极具杀伤力的剑气；刘承重发现的新秘法则能在较短时间内大幅加速内力、境界与恢复，使原本就强的剑气体系被进一步放大。

所以《剑经》不是“专破剑气”的克制秘籍。

它更像另一条高度依赖个人的剑术 / 剑意道路：需要罕见天赋、丰富实战、对人和剑的理解，以及在一次次真实危险中继续活下来。

剑意也不是隐藏经验条。危险不会自动加属性；真正增长的是对距离、意图、变化、取舍、修正和人的理解。

## 范野与张之焘

范野离开宗门时已经是天下数一数二的高手。

他从小打到大，战斗经验极其丰富，对剑早有自己的完整认识。一个高手也许能胜他，但“胜他”和“杀他”是两回事；真要杀范野，合理方式必须是组织化围杀，而不是某个高手单挑挑战。

张之焘认可范野，也正因为范野已经是一个真正的顶尖剑客，并且仍然有继续理解的能力。

张离开前把自己对《剑经》、剑意和剑术的一些认识传给范野，但当时：

- 范野并没有完全理解；
- 更没有学成“张之焘的剑”；
- 张仍比他高一层；
- 范野的主要武力仍来自剑宗正统；
- 真正更深扎进范野心里的，反而是张带他看见的人间烟火。

范野最后必须长出自己的剑。

## 当前开篇强候选

正文不再从范野少年成长顺叙。

当前最强方向进一步收紧为：**范野离宗后不久，剑宗开始组织化追杀；正文直接从这场围杀进入。**

可以极轻地碰一下名字：

> **城郭之外谓之野。范野生在城里。**

随后他已经在城外，有人在杀他。

离宗时范野必须付出真实代价：宗门装备、身份、资源、某些专属传承甚至部分修为如何处理，仍待细化，但不能让他“带着全部福利轻松辞职”。

第一次围杀中，**郴竹再次与范野相遇并救他** 是当前强候选。两人少年时曾有一次并不深的旧缘：范野曾在自己有选择权时，没有顺手把郴竹推向对她不公的结局；多年后，郴竹在范野最狼狈的时候给他留下一条路。

这不是“报恩女主”，而是两个独立高手之间一笔很轻、很久以后才真正显出重量的旧债。

少年范野、王月出三败、张之焘崛起、龙默与徐辰的旧关系都沉入前史，只在当前剧情需要重新解释人物时穿插。

> **回忆不是补背景，而是重新解释现在。**

## 当前人物名（暂定）

- **范野**
- **郴竹**
- **张之焘**
- **王月出**
- **刘承重**
- **龙默**
- **徐辰**
- **俞大千**（古代大剑师）

名字都有私人暗纹，但原则不变：

> **梗可以深埋，名字必须先是名字。**

现实彩蛋不能成为理解人物的前提，也不能为了露梗专门搭戏。

## 创作原则

- 世界不是为主角搭建的舞台；范野不存在，各方也会继续行动。
- 新武 / 密功必须真的强。
- 范野必须拥有多个真实可选项；如果选择刘承重，他也能真正进入核心利益圈、飞黄腾达。
- 《剑经》不能变成作者的人生哲学讲义；绝大部分内容首先必须是真正的剑学。
- 偶尔出现的一两句《剑经》文字，可以在后来的人物选择中产生回声，但正文绝不解释“这句话其实是在讲人生”。
- 群众不能只有一种态度：拥护、获利、忍耐、退出、躺平、阳奉阴违、偷偷抵抗、公开反抗都应存在。
- 最终改变秩序不能只靠一个英雄，而应包含大量分散的“不再配合”。
- 范野不会因为最有良知、最能打就自动最会治理，也不会成为新宗主。
- 龙默负责收拾残局不等于龙默的制度是作者答案。
- 张之焘影响范野主要靠人生与带他看见真实人间，不靠讲道理。
- 老医师必须先作为一个人活着，后续受辱也不能只为主角回来报仇服务。
- 不用数值化境界、系统、穿越、血脉觉醒或临场加点。
- 故事可以慢，但不能空。
- 幽默顺带发生，一句话尽量同时干两件事。
- 现实乒乓、Dota 等只作为更早一层灵感，绝不继续规定正文剧情。

## 当前阶段

当前优先级不是继续堆大事件，而是：

1. 继续养活范野、张之焘、王月出、刘承重、郴竹；
2. 做实《剑经》、俞大千、剑宗正统剑气三者的关系；
3. 做实张之焘—王月出—龙默—徐辰这一代的前史；
4. 验证“离宗后围杀 + 郴竹救援”的开篇；
5. 再设计第一条完全属于小说自己的现实冲突；
6. 只拆未来 10–15 章，滚动写、滚动复审。
