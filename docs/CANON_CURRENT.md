# 当前 Canon 总表

> 本文件用于快速索引当前已经锁定的强 canon。具体细节以各专题文档为准；若本文件与更新日期更晚、且明确声明覆盖关系的专题文档冲突，以后者为准。

## 2026-08-20：东土入场最新修正

- 《天下狩猎》在范野坠江时正式结束，东土不是“天下狩猎第二赛区”。
- 东土顶级宗门不会默认争抢范野；其首要反应是观察、判断、结交、招揽和评估。
- 范野在卢大有船上**没有提前想清楚东土下一步，也没有预谋“主动曝光自己”**。他在船上首先只是活下来、养伤、恢复。
- 范野抵达东土、去办理客籍时仍处于清醒但真实的迷茫状态。
- 客籍小吏问“姓名？”时，范野才第一次真正决定：是否继续用假名活下去，还是以真实身份站在东土。
- 从纯粹自保角度看，范野当然更愿意不用真名，因为他知道一旦公开，用不了多久就会麻烦缠身；东土本地想剑谱的散修以及中州继续追来的少量亡命徒、疯剑客都会循名而至。但这些人在范野眼里大多只是杂鱼，不值得他畏惧。
- 真正让范野决定报真名的关键，是卢大有：如果范野隐姓埋名消失，卢大有就会变成后来追查范野最直接、最有价值、也最容易下手的线索。范野不能让救命恩人替自己承担这种危险，更不会多余地要求卢大有替他保守秘密。
- 因此范野最终报出“范野”，把未来的麻烦重新拉回自己身上。这一选择同时意味着：范野第一次以脱离剑宗后的真实自己站在东土。
- 小吏顺口问“不会是中州剑宗那个范野吧？”时，范野一怔，第一反应是“麻烦比自己预想得来得还快”；随后回答：“中州范野。已经不属于剑宗。”
- 小吏不是相信，而是被气笑：在他看来，自己随口递了句戏，眼前这个骗子居然真顺杆演下去了。
- 除中州外，东土、西域、南洋、北海已经普遍存在冒充范野骗吃骗喝、骗财、骗色的人；东土官府甚至可能已经抓过、关过多个“范野”。
- 客籍房场面必须热闹：小吏开骂以后，排队登记的普通人全部加入围观、大笑和接梗。群众会拿自己听来的各种“范野传说”继续调侃，甚至有人觉得“这个演得不错，该赏”，真拿铜钱赏骗子。
- 范野起初只是惊讶小吏居然知道自己，后来听出“这里已经有很多冒牌范野”，才真正懵住；他没想到自己的名声和冒名产业早已先于本人抵达东土。
- 范野最后不争辩，只无奈递出一句：“五毒老三剑上淬的是——”后接特配软筋散正式药名（药名尚未锁定）。
- 现场不会立刻安静，反而先笑得更凶；有人拍腿、扶桌、蹲地捂肚子，认为这个骗子已经开始现场编江湖秘闻。
- 小吏也会大笑着重复：“我他妈……还五毒老三剑上……”然后在重复到一半时突然僵住，因为脑子终于追上这句话意味着什么。
- 小吏先像看鬼一样看范野，随后几乎连滚带爬往里跑，边跑边喊“头——！范野！范野——！”；周围人这才一层一层反应过来，笑声从前排向后排逐渐断掉。
- 客籍房由此自行完成范野的公开曝光。范野不是为了制造轰动才登记真名；公开社会可见性和势力互相注视带来的安全，只是附加结果。
- 范野公开以后仍没有清晰的东土大计划。他先吃饭、养伤、了解东土、观察这个陌生社会如何回应他的出现；有分量的人迟早出现，是后续自然发展，不是他提前布好的棋。
- 卢大有长期喜剧线继续锁定：范野用真名实际上是在救卢大有，但客观结果是卢大有以后再说“范野是我从江里捞上来的”越来越没人信；范野若被求证，只微微一笑：“算是吧。”卢大有这辈子基本翻不了案。
