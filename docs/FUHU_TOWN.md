# 伏虎镇（当前强 Canon）

> 状态：当前强 canon。
>
> 更新时间：2026-08-25。
>
> 本文负责《天下狩猎》开篇舞台伏虎镇的地理、经济、社会质感，以及范野为何在此停下与五毒形成默契战场。正文不需要把本文内容逐条解释给读者；设定应主要通过街道、建筑、人物生活与后续杀局自然显出。

---

# 1. 基本定位

伏虎镇不大。

它地处中州边缘，靠近一处出入中州的关口。镇外很快就是荒凉山地与关道，地理条件恶劣：山石多、土地薄、风大，适合耕种与稳定谋生的条件都不好。

它不是繁华商埠，也不是已经废弃的死镇。

更准确的定位是：

> **一座因为关口和固定商路而不得不存在的小镇。**

走这条关道的主体不是一年几次突然涌来的大型商队，而是几支常年往返、规模不大的固定商队 / 商号车队。

他们带来稳定但有限的过路需求，使伏虎镇能够活下去，却不足以把它养成繁华地方。

伏虎镇的穷，来自恶劣地理、本地生产能力弱、稳定谋生机会少，以及商路本身规模有限。

镇外本来就比镇内安静，荒山、关道、风声属于常态。第一章五毒真正动手以前，**不额外制造“镇外忽然格外安静”“鸟兽失声”等异常征兆**。伏虎镇应当一直像平日一样生活，危险不能靠环境预警。

---

# 2. 镇子的规模与客栈生态

伏虎镇常住人口不多，保持真正意义上的小镇规模。

镇上只有几家客栈 / 脚店。

这些店的经营方式不能理解成面向大量随机旅人的旅游客栈，更接近固定商号长期使用的落脚点：

- 几支熟悉的商队 / 商号常年轮换往返；
- 店家知道哪些商队大致什么时候经过、需要多少房、马料、仓间和热水；
- 商队也习惯固定住某一家，不必每次重新找店；
- 好房、通铺、后院、马棚、货物存放位置会优先留给这些长期熟客；
- 有的商号可以统一结账，或者形成长期账目与人情关系；
- 因为几家小商队错峰往返，有限的客栈床位平日就经常被这类固定客源占据。

因此伏虎镇虽然有几家客栈，**普通散客平日反而很少住进去**。

不是法律意义上的“商队专用”，店门也不会挂着拒绝散客的牌子；只是店家主要靠长期熟客吃饭，对陌生的短住散客缺少兴趣，也不愿轻易打乱已经固定的房间、马棚和货物安排。

这套生态可以概括为：

> **客栈少，熟客固定，房间长期被商队需求吃掉；真正的散客在伏虎镇反而是边缘生意。**

---

# 3. 平安街

镇上的主要街道正式确定为 **平安街**，废弃此前“长安街”称呼。

平安街承担镇内最主要的商路、客栈、马店、杂货与风月生意。名字本身只是很普通的吉利话：靠关道吃饭的人来来往往，求一个平安很自然，不需要另写复杂典故。

平安街可以是镇上最像样、最宽的一条路，但不能因此写出繁华都市中心街道的规模和气象。伏虎镇仍然是贫瘠关道旁的小镇。

---

# 4. 醉仙居

此前“怡情楼”废弃，正式改为 **醉仙居**。

醉仙居是伏虎镇唯一一家妓院，是一栋临平安街的两层木楼，规模不大，也不应写成大城式豪华青楼。

它的客源主要来自：

- 固定往返关道的小商队成员；
- 车夫、脚夫、护卫等随队人员；
- 镇上与周边偶尔有闲钱的男人；
- 少量真正的散客与江湖人。

因此它可以长期存在，但平日生意只是维持得下去，不需要门庭若市。

在伏虎镇这样一个穷、荒、娱乐极少的小地方，**能够进醉仙居花钱逍遥，本身带一点可被旁人识别的身份意味**。

这种“身份”不能夸张成真正的上流阶层。更准确地说：

- 一个男人若能经常进醉仙居，至少说明手里有些现钱；
- 商队里的管事、有余钱的护卫、做成一笔买卖的人，更容易在这里消遣；
- 对镇上的穷人和狗蛋这种孩子来说，醉仙居也是“有钱人才进得起”的成年世界之一；
- 因为镇上只有这一家，它天然比普通酒铺更带一点体面、炫耀和身份展示的意味。

正文不需要把这层社会意义解释出来，可通过谁进去、谁只能在门外看、男人如何谈论它自然显出。

## 4.1 “醉仙居”这个名字的来历

醉仙居原先另有名字，**旧名如今已经没人记得清楚**。

多年以前，一名富商途经伏虎镇，在这里停留数日。镇上传下来的说法是，他在楼里既喝得酒醉，也过得“人醉”，临走时兴致很好，嫌原来的名字扫兴，索性题下“醉仙居”三个字。

富商同时出钱重做门脸，并做了那块与小镇和楼本身体量都明显不相称的巨大竖招牌。老板既得了钱，自然愿意换名。

此后年月过去，富商是谁、醉仙居原先叫什么都渐渐没人说得清，只有“醉仙居”三个字和那块大木牌一直留下来。

这段历史的意义在于：

> **名字与招牌来自同一次外乡富商的酒醉、人醉和一时豪兴。**

它不是伏虎镇昔日繁华的证据。

## 4.2 那块不相称的竖招牌

醉仙居二层临街处有挑梁，下面悬着一块与楼本身体量明显不相称的巨大竖式木招牌。

招牌由上至下写着：

> 醉  
> 仙  
> 居

当前锁定：

- 招牌尺寸偏大、用料厚实；
- 通过二层挑梁悬在临街上方，落下时会进入街面，不是贴墙垂落；
- 从二层高度坠下足以杀死一个孩子；
- 醉仙居一直正常经营和维护，招牌可以旧、可以补漆，但不能自然摇摇欲坠；
- 五毒后来主动对悬挂 / 承重结构做手脚，并保留最终触发手段；
- 正文不必解释机关工程细节。

> **招牌先是伏虎镇多年来人人看惯的一件东西，后来才被五毒拿来杀人。**

# 5. 平安街核心空间关系

当前锁定：

> **悦来客栈与醉仙居隔着平安街错对门而立。**

不是两扇门正正相对，而是沿街前后错开一段距离。

- 悦来客栈是固定商队常用的落脚点之一；
- 醉仙居在斜对街，二层巨大竖招牌挑在街面上方；
- 范野进入伏虎镇以后可以主要在悦来客栈这一侧的街边 / 墙边停留；
- 狗蛋平日在这一带讨生活，对客栈、醉仙居、街宽和招牌都很熟；
- 后续狗蛋被逼着朝悦来客栈方向跑并喊救命时，会经过醉仙居前方的招牌坠落区域；
- 范野若去救，需要横过 / 切入一段街面，从而自然进入五毒预先设计的攻击窗口。

空间关系应在五毒动手以前自然成为读者熟悉的生活背景，不能等杀局开始才突然补建筑说明。

---

# 6. 范野为什么选择伏虎镇

范野并不是害怕五毒继续跟踪。

五毒早已知道他的位置，范野也知道五毒一路跟着。到伏虎镇时，他真正要解决的是：

> **怎样让这几个极谨慎、极有耐心的人终于愿意真正下场。**

纯粹荒野对范野太有利。范野若刻意选择一片开阔地或自己更容易控制的山林，五毒完全可以继续不动，保持尾随，等待更好的机会。

伏虎镇提供了双方都能接受的风险：

- 房屋与巷道可以藏人；
- 有普通居民、商队人员和零散过客；
- 有屋顶、院墙、建筑与杂物可以提前布置；
- 五毒能制造复杂变量；
- 范野仍有足够空间观察、移动和应变。

> **伏虎镇不是范野的最佳战场，而是范野停下以后五毒也愿意下注的战场。**

范野进入镇后不再继续赶路，本身就是无声邀战。五毒能够看懂。

---

# 7. 范野在伏虎镇的日常状态

范野停下来以后 **不会只坐在原地干等五毒**。

他有自己的日子要过，会在伏虎镇内外随意走动：沿街看看、去镇外走走、经过后巷、关道、坡地，与当地人偶尔有正常的简短交流，也会自然接触这里的风土与生活。

这些活动客观上使他逐渐熟悉伏虎镇的地貌、道路、出入口和生活节奏，但正文不能把他写成拿着作战任务“勘察地形”的侦察者。对普通人和狗蛋而言，他只是一个没什么明确营生、每天不知道去哪里转一圈又回来的落魄外乡人。

在读者真正得到“范野”这个名字以前，应尽量保留这个灰衣落魄男子的神秘感：

- 不进入他的内心解释目的；
- 不解释他为什么每天出去；
- 不通过旁白告诉读者他正在熟悉战场；
- 不提前用细节暗示“真正高手”；
- 在老三之死以前，不主动展示任何超出普通壮汉 / 普通江湖人的武力。

范野本身体格高大、结实强壮，又带着剑，单凭外形就足以让普通人直觉上觉得这个人打架不会吃亏；不需要额外安排“露一手”证明。

---

# 8. 范野与客栈

不能再解释成“范野怕客栈暴露行踪”。

范野根本不怕五毒知道自己在哪里，他就是在等五毒。

也不必为了战术强行解释成“范野拒绝住店”。伏虎镇本身的客栈生态已经能够提供现实条件：

- 客栈数量少；
- 主要服务长期绑定的小商队 / 商号熟客；
- 房间、通铺、马棚与院落平日就经常有固定安排；
- 陌生散客不是店家最想接的生意。

因此范野在平安街、悦来客栈附近找一处有墙可倚、有一定遮风条件的地方停下休息，不需要被写成一场刻意展示高明的战术选择。

对普通人，这只是一个落魄外乡人在街边歇脚。

对狗蛋，这是一个陌生、落魄、看起来连客栈都没住进去的外乡人。

对五毒，真正重要的信息只有一个：

> **范野停下来了。**

具体正文是否写范野进店询问、被告知无房，不锁死；避免为了说明设定专门安排解释性桥段。

---

# 9. 五毒在伏虎镇的落脚原则

伏虎镇越小，五个陌生江湖人一起住进客栈就越显眼。

因此五毒不能以“五人同行入住一家店”的形式公开出现。

当前原则：

- 五人早已跟踪范野多时，不需要和范野同一天同时进镇；
- 可以提前分批进入、混入商队人员、以不同身份短暂停留；
- 一两个人可以利用散客身份进入客栈 / 脚店，其余人可以利用镇外荒地、废屋、临时住处或其他不起眼位置落脚；
- 真正动手前，五人甚至没有必要都长期睡在镇内；
- 正文不必把五毒住宿写成悬疑解谜，但不能让他们五个人堂而皇之住在一起破坏“谨慎、耐心、善于藏线”的基本能力。

更重要的是：**五毒进入伏虎镇以后，镇子的日常不应因此出现肉眼可见的异常。** 商队照常来去，悦来照常忙闲，醉仙居照常营业，镇民照常过日子。五毒的能力恰恰体现在他们已经观察、准备了数日，而狗蛋这类整天盯着生面孔讨生活的人也没有意识到一场杀局正在形成。

具体五毒每个人住在哪里暂不锁死。

# 10. 狗蛋与伏虎镇

狗蛋十二三岁。

伏虎镇常住人口不多，本地人彼此较熟。狗蛋长期偷、骗、诈以后，在本镇很多商贩眼里已经是熟面孔，这会让他在本地越来越难下手。

镇上的稳定工作机会本来就少，成年人尚且争活，一个没有家庭与稳定依靠、名声又已经坏掉的孩子更容易被排除在正经营生之外。

必须同时保留两面：

- 狗蛋确实偷、骗、挥霍、学坏，不是纯洁受害者；
- 伏虎镇也确实没有给这种孩子很多可靠的活路，不能把他的处境简单归结为“懒”。

狗蛋不会只盯着范野一个人薅羊毛。他仍然有自己原本的生活：找吃的、偷骗、赌、在镇里晃荡、观察来往生人。范野只是因为陌生、落魄、独自出现，又始终没有离开，逐渐变成他日常里一个越来越值得琢磨的人。

狗蛋与范野在五毒出现前的具体关系，见 `CH01_FIVE_POISONS_TRIGGER.md`。

# 11. 正文呈现纪律

第一章正文目前暂停编写；以下记录仅作为以后重新动笔时的约束。

- 可以先给伏虎镇一个足以让读者站稳脚的简短轮廓，但不能写成地方志。
- 平安街、悦来客栈、醉仙居与竖招牌要在后续数日生活中反复自然出现，不能开头介绍完便失去作用。
- 伏虎镇的生活必须继续向前：商队会来会走，悦来会忙会闲，醉仙居有昼夜差异，镇民各忙各的。
- 日常不必每一件事都承担伏笔功能。镇子首先要像一个真实地方，然后其中的街、巷、孩子、招牌才会被五毒利用。
- 五毒真正动手以前不制造阴风、死寂、鸟兽异常等危险提示。
- 范野不主动展示武功，不用“脚步异常沉稳”“无意露一手”等方式替高手身份预充值。
- 范野的很多活动可以不向狗蛋和读者解释，只让人知道他出去、回来，偶尔从不同方向出现。
- 具体叙事关系、狗蛋好奇与拉人入伙的细节，以 `CH01_FIVE_POISONS_TRIGGER.md` 为准。
