# 伏虎镇（当前强 Canon）

> 状态：当前强 canon。
>
> 更新时间：2026-08-25。
>
> 本文负责《天下狩猎》开篇舞台伏虎镇的地理、经济、社会质感，以及范野为何在此停下与五毒形成默契战场。正文不需要把本文内容逐条解释给读者；设定应主要通过街道、建筑、人物生活与后续杀局自然显出。

---

# 1. 基本定位

伏虎镇不大。

它地处中州边缘，靠近一处出入中州的关口。镇外很快就是荒凉山地与关道，地理条件恶劣：山石多、土地薄、风大，适合耕种与稳定谋生的条件都不好。

它不是繁华商埠，也不是已经废弃的死镇。

更准确的定位是：

> **一座因为关口和固定商路而不得不存在的小镇。**

走这条关道的主体不是一年几次突然涌来的大型商队，而是几支常年往返、规模不大的固定商队 / 商号车队。

他们带来稳定但有限的过路需求，使伏虎镇能够活下去，却不足以把它养成繁华地方。

伏虎镇的穷，来自恶劣地理、本地生产能力弱、稳定谋生机会少，以及商路本身规模有限。

---

# 2. 镇子的规模与客栈生态

伏虎镇常住人口不多，保持真正意义上的小镇规模。

镇上只有几家客栈 / 脚店。

这些店的经营方式不能理解成面向大量随机旅人的旅游客栈，更接近固定商号长期使用的落脚点：

- 几支熟悉的商队 / 商号常年轮换往返；
- 店家知道哪些商队大致什么时候经过、需要多少房、马料、仓间和热水；
- 商队也习惯固定住某一家，不必每次重新找店；
- 好房、通铺、后院、马棚、货物存放位置会优先留给这些长期熟客；
- 有的商号可以统一结账，或者形成长期账目与人情关系；
- 因为几家小商队错峰往返，有限的客栈床位平日就经常被这类固定客源占据。

因此伏虎镇虽然有几家客栈，**普通散客平日反而很少住进去**。

不是法律意义上的“商队专用”，店门也不会挂着拒绝散客的牌子；只是店家主要靠长期熟客吃饭，对陌生的短住散客缺少兴趣，也不愿轻易打乱已经固定的房间、马棚和货物安排。

这套生态可以概括为：

> **客栈少，熟客固定，房间长期被商队需求吃掉；真正的散客在伏虎镇反而是边缘生意。**

长安街是镇上主要街道与外来人最容易经过的地方。街名可以比镇子本身更气派，这种轻微反差可以保留，但正文不需要专门解释街名历史。

# 3. 怡情楼

怡情楼是伏虎镇唯一一家妓院。

它是一栋临长安街的两层木楼，规模不大，也不应写成大城式豪华青楼。

它的客源主要来自：

- 固定往返关道的小商队成员；
- 车夫、脚夫、护卫等随队人员；
- 镇上与周边偶尔有闲钱的男人；
- 少量真正的散客与江湖人。

因此它可以长期存在，但平日生意只是维持得下去，不需要门庭若市。

不过在伏虎镇这样一个穷、荒、娱乐极少的小地方，**能够进怡情楼花钱逍遥，本身带有一点可被旁人识别的身份意味**。

这种“身份”不能夸张成真正的上流阶层，也不是只有富人才进得去。更准确地说：

- 一个男人若能经常进怡情楼，至少说明手里有些现钱；
- 商队里的管事、有余钱的护卫、做成一笔买卖的人，会比穷脚夫更有资格在这里消遣；
- 对镇上的穷人和狗蛋这种孩子来说，怡情楼既是风月场，也是“有钱人才进得起”的地方之一；
- 因为镇上只有这一家，它天然比普通酒铺更带一点体面、炫耀和成年世界的意味。

正文不需要把这种社会分层说透，可以让人物态度、谁进门、谁在门外看自然显出来。

## 3.1 那块不相称的竖招牌

怡情楼二层临街处有挑梁，下面悬着一块与镇子、楼本身体量明显不相称的巨大竖式木招牌。

招牌由上至下写着：

> 怡  
> 情  
> 楼

这块招牌不是伏虎镇曾经繁华的遗物，也不是怡情楼昔日鼎盛的证明。

镇上传下来的说法是：多年前一名富商经过伏虎镇，在这片荒凉地方停留，某夜在怡情楼过得十分尽兴。临走时兴致未消，觉得在这种荒凉处经历的风月有一种与大城完全不同的调调，于是出钱替怡情楼做了一块格外阔气的招牌。

传言在镇上流传多年，真假无需验证。

重要的是：

- 富商当年确实留下了一块尺寸偏大、用料厚实的竖式木招牌；
- 招牌与怡情楼本身的普通规模形成反差；
- 招牌通过二层挑梁悬在临街上方，落下时会进入街面，而不是贴墙垂落；
- 怡情楼后来一直正常使用和维护，没有理由因为镇子穷就拆掉；
- 到范野进入伏虎镇时，这块招牌仍在，可以旧、可以多次补漆，但不能自然摇摇欲坠；
- 后续五毒主动对悬挂 / 承重结构做手脚，在关键瞬间触发坠落。

> **招牌先属于一个富商偶然留下的风流故事，后来才被五毒拿来杀人。**

# 4. 长安街核心空间关系

当前锁定：

> **悦来客栈与怡情楼隔着长安街错对门而立。**

不是两扇门正正相对，而是沿街前后错开一段距离。

这个空间关系既服务伏虎镇日常，也服务后续五毒杀局：

- 悦来客栈是固定商队常用的落脚点之一；
- 怡情楼在斜对街，二层竖招牌挑在临街上方；
- 范野进入伏虎镇以后主要停留在悦来客栈这一侧的街边 / 墙边；
- 狗蛋平日就在这一带讨生活，对客栈、怡情楼、街宽和招牌都非常熟悉；
- 后续狗蛋被逼着朝悦来客栈方向跑并喊救命时，会经过怡情楼前方的招牌坠落区域；
- 范野若去救，需要横过 / 切入一段街面，从而自然进入五毒预先设计的攻击窗口。

正文前段描写伏虎镇时，应把悦来客栈、怡情楼、竖招牌与周边街面自然带出来，让读者提前形成空间印象；不能等杀局开始才突然补建筑说明。

# 5. 范野为什么选择伏虎镇

范野并不是害怕五毒继续跟踪。

五毒早已知道他的位置，范野也知道五毒一路跟着。到伏虎镇时，他真正要解决的是：

> **怎样让这几个极谨慎、极有耐心的人终于愿意真正下场。**

纯粹的荒野对范野太有利。范野若刻意选择一片开阔地或自己更容易控制的山林，五毒完全可以继续不动，保持尾随，等待更好的机会。

伏虎镇提供了双方都能接受的风险：

- 房屋与巷道可以藏人；
- 有普通居民、商队人员和零散过客；
- 有屋顶、院墙、建筑与杂物可以提前布置；
- 五毒能制造复杂变量；
- 范野仍有足够空间观察、移动和应变。

所以伏虎镇不是范野的“最佳战场”。

> **它是范野故意停下以后，五毒也愿意下注的战场。**

范野进入镇后不再继续赶路，本身就是无声邀战。五毒能够看懂。

# 6. 范野与客栈

不能再解释成“范野怕客栈暴露行踪”。

范野此时根本不怕五毒知道自己在哪里，他就是在等五毒。

也不必为了战术强行解释成“范野拒绝住店”。

伏虎镇本身的客栈生态已经能够提供更自然的现实条件：

- 客栈数量少；
- 主要服务长期绑定的小商队 / 商号熟客；
- 房间、通铺、马棚与院落平日就经常有固定安排；
- 陌生散客并不是店家最想接的生意。

因此范野在长安街、客栈附近找一处有墙可倚、有一定遮风条件的地方停下休息，并不需要被写成一场刻意展示高明的战术选择。

他可以只是抵达伏虎镇以后停下来，不急着找房，也不在意睡得是否体面。

对普通人，这只是一个落魄外乡人在街边歇脚。

对狗蛋，这是一个陌生、落魄、看起来连客栈都没住进去的外乡人。

对五毒，真正重要的信息只有一个：

> **范野停下来了。**

具体正文是否写范野进店询问、被告知无房，目前不锁死；避免为了说明设定专门安排解释性桥段。

# 7. 五毒在伏虎镇的落脚原则

伏虎镇越小，五个陌生江湖人一起住进客栈就越显眼。

因此五毒不能以“五人同行入住一家店”的形式公开出现。

当前原则：

- 五人早已跟踪范野多时，不需要和范野同一天同时进镇；
- 可以提前分批进入、混入商队人员、以不同身份短暂停留；
- 一两个人可以利用散客身份进入客栈 / 脚店，其余人可以利用镇外荒地、废屋、临时住处或其他不起眼位置落脚；
- 真正动手前，五人甚至没有必要都长期睡在镇内；
- 正文不必把五毒住宿写成悬疑解谜，但不能让他们五个人堂而皇之住在一起破坏“谨慎、耐心、善于藏线”的基本能力。

具体五毒每个人住在哪里暂不锁死，待第一章空间关系与动手路线最终确定后再细化。

# 8. 狗蛋与伏虎镇

狗蛋十二三岁。

伏虎镇常住人口不多，本地人彼此较熟。狗蛋长期偷、骗、诈以后，在本镇很多商贩眼里已经是熟面孔，这会让他在本地越来越难下手。

镇上的稳定工作机会本来就少，成年人尚且争活，一个没有家庭与稳定依靠、名声又已经坏掉的孩子更容易被排除在正经营生之外。

必须同时保留两面：

- 狗蛋确实偷、骗、挥霍、学坏，不是纯洁受害者；
- 伏虎镇也确实没有给这种孩子很多可靠的活路，不能把他的处境简单归结为“懒”。

范野这样一个陌生、落魄、独自出现、还在街边休息的人，因此会天然成为狗蛋眼里的新目标。

---

# 9. 正文呈现纪律

正文不应重墨讲解伏虎镇历史，也不需要老人出来感慨过去。

第一章只需要让读者迅速感受到：

- 镇子不大；
- 地处荒凉关道，靠近中州出入关口；
- 几家客栈主要围着固定小商队做长期熟客生意；
- 普通散客在这里反而不常见；
- 怡情楼是唯一妓院，规模普通，但在伏虎镇能进去消费本身带一点身份意味；
- 怡情楼二层临街挑梁悬着那块过分阔气的竖招牌，并有一个荒凉地方里偶然留下的富商风流传闻；
- 悦来客栈与怡情楼隔长安街错对门而立，这组空间关系应在前文自然出现；
- 外来人一出现就容易被狗蛋这种孩子注意；
- 范野停下以后，五毒能够读懂其中的意味。

其余历史和社会结构应通过后续行动自然显出。
