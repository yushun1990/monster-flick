# 一、正文从“天下狩猎”进入

正文不从少年范野顺叙，也不从剑宗大厅慢慢交代离宗。

可以极轻地碰一下名字：

> **城郭之外谓之野。范野生在城里。**

随后范野已经离开剑宗。

从他走出宗门控制范围的那一刻：

> **天下狩猎已经开始。**

这不是预先搭好的山谷围杀点。

场景沿道路、客栈、渡口、城镇、商路与势力边界持续移动。

# 二、开篇必须立即让读者相信什么

1. 范野已经是天下数一数二的绝顶高手；
2. 有人可能比他强，但“胜他”和“杀他”是两回事；
3. 他离宗后没有自己的名剑，也失去宗门身份、资源、医疗、情报与接应；
4. 他不是江湖白痴，真正新问题是长期从整个社会信息网络中消失；
5. 各方目标不同：杀、抢活人、赌秘籍、套情报、阻止剑宗收网；
6. 大势力不能轻易公开承认自己在抢剑宗前核心人物，因此隐藏身份、蒙面和误判天然成立；
7. 剑宗最初并不急着第一时间下场，而想让别人先消耗范野和彼此；
8. 刘承重完整长生计划前期不揭；
9. 张之焘完整前史也不一次讲完。

范野的强不能靠旁白报排名，要靠：

- 敌人的人数；
- 情报准备；
- 战术谨慎；
- 宁愿抓活也不敢轻易单挑；
- 每次交手后对他的重新估价。

# 三、半年前的大盟会：裂痕公开化

几年一次、几大势力共同处理重大江湖事务的会盟，是重要前史节点。

本次大议题之一：

> **联合诛杀张之焘。**

这不是“所有人都相信一本秘籍”。

不同势力算盘不同：

- 散修 / 剑痴：真信失落《剑经》；
- 中小门派：更怕张本人不可预测；
- 大宗门：更想把张本人变成战略变量、盟友或筹码；
- 剑宗：需要解决一个无法控制、持续搅动内部与外部秩序的人。

范野被推为领军：

- 足够强；
- 最熟悉张的剑；
- 天下已看出两人关系不同寻常；
- 让范领军本身就是公开割席 / 忠诚测试。

范野拒绝。

不需要长篇价值宣言。

这个拒绝本身就让全天下确认：剑宗与最耀眼的新一代人物之间出现真正裂痕。

随后半年，任务、资源、调查、师徒关系、核心信任逐渐恶化，最后走到离宗。

# 四、张之焘为什么成为“天下问题”

## 4.1 玄清宗七剑

二流门派玄清宗二长老祸害贫民一家，宗门内部认为赔钱、训斥、压事已经处理。

张知道以后，一人上门。

> **张一人入玄清宗，如入无人之境。**

二长老七剑而死。

最后一剑保留 Dota1 剑圣式凌空下劈的决绝视觉，但必须长成本书真实剑术动作。

玄清掌门握住剑柄却没有拔。

不是被剑意定住。

> **张真正击败的不是掌门的剑，是掌门拔剑的决心。**

必须允许正直反对意见存在：

> **二长老该死，是一回事。张之焘想杀谁便杀谁，是另一回事。**

## 4.2 剑宗正式逐张

公开理由必须真实成立：

- 擅闯他宗；
- 私杀长老；
- 越过既有处置；
- 破坏宗门盟约；
- 以个人裁决替代共同规则。

过程可以是：停职 → 调查 / 限制 → 要求交代 / 道歉 / 承诺“不再擅自干涉他宗内部事务” → 张拒绝 → 正式逐出。

刘承重不是凭空栽赃，而是利用一件真的事处理更深的威胁。

## 4.3 深层原因

刘的长生 / 新法工程在张进入以前已推进多年。

> **湖水本来就快翻，张之焘是一块砸进去的石头。**

张未必知道秘法机制，却总把抽象管理问题重新变成具体的人。

> **你们越来越不把人当人了。**

这足以让刘无法容忍。

# 五、范野离宗：不是“两清”

范野可以归还：

- 名剑 / 公产兵器；
- 身份牌、职印、权限；
- 宅院、坐骑、俸禄；
- 药物、情报、陪练、医疗支持；
- 明确属于宗门秘密且约定不得传播的传承；
- 组织指挥权与部属。

明确否决：

- 自废修为；
- 把二十多年身体、经验、个人剑意全部解释成宗门财产；
- “挨三掌 / 废三成功力”式方便仪式。

真正矛盾：

> **这份恩永远算不清，但恩不能自动变成永久所有权。**

具体身体 / 现实代价仍待继续设计。

---

# 六、刘承重如何把范野变成天下目标

刘故意让天下确认：

- 范野确已离宗；
- 状态不佳；
- 名剑与资源已收回；
- 张可能把“俞大千失落真《剑经》”传给他。

他在复用处理张之焘时已经验证过的办法：

> **把一个无法控制的人，改写成所有人都想争夺的东西。**

范野比张更刺痛刘，因为范野不是外来异类，而是剑宗自己培养出的最大成功者之一。

---

# 七、龙默 / 徐辰：目标不是“救范野”

刘最大的优势：

> 别人抢，别人杀，剑宗看。

龙默与徐辰真正需要破坏的是：

> **剑宗始终站在棋盘外坐收渔利的能力。**

## 龙默

- 不亲自到现场；
- 不发万能救命信；
- 只在核心调度、规则、人员、道路或信息封闭上留下极小缝隙；
- 这个缝隙不能本身等于救援方案。

## 徐辰

- 不把完整秘密送给外部势力；
- 让马料、药材、客栈、渡口、高手调动、道路异常这些真实蛛丝马迹被正确的人看见；
- 大宗门靠自己的情报系统推理。

两人可以不共谋，也不需要知道郴竹会出现。

当前最大技术难点之一仍是：

> **怎样让剑宗真正出现“再不下场，范野就会脱离控制”的现实局面。**

# 八、逍遥峰为什么进入天下狩猎

旧版“峨眉 / 郴竹外围警戒 / 不知道目标”全部废除。

天下狩猎发生时：

- 小师妹已经是现任逍遥峰掌门；
- 她已经真正坐稳三峰；
- 逍遥峰很强，但仍需要长期经营威慑、商路、利益和外部武力。

小师妹最初看范野，至少首先看见：

> **一把突然离开剑宗的绝世宝刀。**

她并不是为了吞剑宗地盘，也不是单纯“想见见有趣的人”。

她自己是峰主，郴竹又是最重要的姐姐；逍遥峰长期需要真正能向外挥出的高手。

因此她决定抓范野。

---

# 九、郴竹：从行动负责人变成隐瞒者

郴竹就是逍遥峰抓范野的行动负责人。

她调人封路、盯线、截线、处理其他势力，自己作为最强机动点追最后机会。

最终只有她抵达最后战场：

- 最后一拨追杀者已经死完；
- 范野确认没人还能杀自己以后才倒；
- 郴竹先按任务目标确认现场、伤势和是否有诈；
- 她先把范野拿到手；
- **处理伤势时才通过特殊旧疤认出童年救命故人。**

顺序必须锁死。

## 9.1 为什么不报

身份未确认前暂不汇报，本来就符合专业习惯。

认出以后，她凭多年经验得出一个不需要十步推演的判断：

> **小师妹那里是个危险的地方。**

她见过太多高手、天才在小师妹的铁血政治下低头，也见过没低头的人怎么死。

她知道妹妹会爱惜范野。

也正因为如此，宝刀到了妹妹手里是真要砍人的。

范野刚从一个组织里走出来；郴竹无法保证他进入另一个权力结构以后永远愿意出剑，也无法保证两人碰到真正的“不”时不会见血。

所以：

> **这条消息不能进入逍遥峰权力系统。**

---

# 十、郴竹的离开念头

旧版“她从小就计划妹妹长大后离开”废除。

她原本想的恰恰是：

> **妹妹长大以后，我还是留在她身边。**

后来小师妹真的强到不需要她护着，老大老二也已不是对手，师父师娘又都不在，从前那个家的生活形态彻底结束。

所以范野出现以前，她已经偶尔想到：

> **也许我可以出去。**

只是念头。

范野的出现让它变成真正可想象的人生。

> **郴竹不是因为范野才想离开。范野让门外第一次变得真实。**

---

# 十一、小师妹与范野的后续冲突

小师妹最在意的是郴竹，不是范野。

她可以非常清楚：范野没有勾引姐姐、没有劝姐姐离开，姐姐本来就已经动过念头。

知道不等于不恨。

她完全可以因为私人恶意让范野真实倒霉。

例如：

- 把范野一段踪迹卖给仍在追他的剑宗；
- 换一项自己平时根本不在乎的经贸利益；
- 表面是一笔正常峰主交易；
- 实际推动她出手的是“我就是想让他倒霉”。

她不是把范野收成自己的兵。

她真正可怕的是能拨动范野周围原本存在的政治力量。

私人红线：

> **范野可以倒霉，郴竹不能动。**

如果剑宗借她给的线索把郴竹也放进杀局，她会翻脸。

---

# 十二、野外小院与范野醒来

郴竹把昏迷范野藏进私人野外小院。

不是机关堡垒，安全来自没人知道此时该往那里找。

院中只有跟随郴竹多年的老奴：成熟武林高手、内力醇厚、懂伤毒和藏人，对郴竹有真实礼法上下。

郴竹在范野醒来之前已经离开，回到外部继续处理狩猎后续。

范野醒来：

1. 先知道自己还活着；
2. 不说话；
3. 看伤、门窗、出口、光、外部声音、束缚、药、老人；
4. 看手边有没有能用的兵器；
5. 不摸“自己的佩剑”，因为名剑早已还宗门；
6. 形成判断以后才说：

> **“我昏了多久？”**

老人不答，他不连续追问。

# 十三、外部天下必须持续推进

如果所有人一直盯剑宗内部，异常会太快被发现。

> **外部天下负责让故事一直往前跑，剑宗内部异常负责一直往下沉。**

必须有即使范野不存在也会发生的真实冲突：

- 地盘；
- 渡口 / 港口；
- 商路；
- 药材；
- 矿产；
- 宗门兼并；
- 难民；
- 联盟；
- 护送；
- 刺杀；
- 改革；
- 谈判。

时代底色：

> **旧的江湖均衡正在松动。**

# 十五、结局原则

- 刘承重倒下不等于世界自动变好；
- 范野不当宗主；
- 龙默更适合收拾剑宗现实残局；
- 小师妹继续是逍遥峰真正掌权者；
- 郴竹最终走或留，必须由故事发展，而不是开篇预设“任务结束便离开”；
- 不给出完美新制度；
- 人物用不同人生给出不同答案。
