# 创作推进计划

## 总原则

不要按软件项目方式一次性把整部长篇拆完。

当前采用：

> **人物做深 → 前史关系做实 → 从“离宗当天”验证开篇 → 再建立离宗后的现实主线 → 只拆未来 10–15 章 → 写作 → 复审 → 滚动推进。**

最重要的纪律：

> **先把人养活。后面他们自己会惹事。**

当前大纲仍未完成。`OUTLINE.md` 记录的是 v1 结构方向，不是冻结骨架。

- [x] 新武必须真的强
- [x] 主角无系统 / 穿越 / 血脉外挂 / 临场加点
- [x] 不做数值化境界表
- [x] 重要人物必须拥有独立利益与人生
- [x] 刘承重的秩序必须真实有效、真实有人受益
- [x] 群众不能只有“受害 / 拥护”一种态度

- [x] 龙默、徐辰与张之焘同代
- [x] “霸王拧”是术 / 斗争方式，不自动携带政治伦理答案

# P1 — 先把核心人物养活

当前人物组：

1. 范野
2. 张之焘
3. 王月出
4. 刘承重
5. 郴竹
6. 龙默
7. 徐辰
8. 老医师 / 药师

对应 Issues：#1–#5、#9。

## 每个人物至少回答

- 从哪里来？
- 过去真正失去过什么？
- 今天最舍不得什么？
- 真正想要什么？
- 什么事情能妥协，什么不能？
- 面对诱惑时有哪些真实可选项？
- 最不愿承认自己的哪一面？
- 如果范野不存在，他 / 她仍会怎样活？

人物卡不能停在“勇敢、聪明、善良、狂、稳”等标签。

验收标准：

> **给一个具体局面，不看大纲也大致知道这个人会怎么选，而且能解释为什么。**

# P1A — 上一代关系先做实

这一层目前非常关键，因为它决定正文回忆有没有重量。

## 张之焘

- 生于野，后来入宗；
- 不是少年成名，是后来的黑马；
- 一路上升时遭遇具体白眼与资源差别；
- 三胜王月出发生在不同阶段；
- 登顶后看见“正宗”内部复杂而体面的肮脏；
- 本来就准备离开，范野只是恰好在此时接住霸王拧与他的部分人生经验。

## 王月出

- 家族说大不大、说小不小；
- 张出现前是宗门顶级天才；
- 连输三次后逐渐被冷落；
- 是范野主动选择他为师；
- 范野成功后，他重新得到宗门信任、资源、地位、家族荣光和家庭稳定；
- 后期真正怕的是再次失去这些失而复得的一切。

## 龙默

- 与张、徐同代；
- 曾长期被王月出压到怀疑自己；
- 张这匹黑马的成功让他意识到第一答案不是唯一答案；
- 最终找到自己的完整、稳定道路；
- 后期具备承担治理与现实残局的能力。

## 徐辰

- 与张、龙同代；
- 可以有地方商武家族背景；
- 天赋、武功、办事和人脉都“路子野”；
- 组织评价：**此人可用，不可大用。**
- 他认识具体的人，而不是抽象的“人民”。

## 老医师

- 不是隐世高人，就是普通好人；
- 张无名时照常给他治伤；
- 张成名后态度也不变；
- 后来成为范野长期固定的医师、药师，关系亦师亦友；
- 范野离宗时只给药，不跟随；
- 后续被新贵日常羞辱时，不以“主角回来报仇”为主要功能。

# P2 — 验证正文开篇

当前最强候选：**范野离宗当天。**

可试的第一句：

> **城郭之外谓之野。范野生在城里。**

只点一下，立刻进故事。

## 开篇必须解决

- 谁来送？谁不来？
- 谁敢走到城门，谁只敢在更早的地方说话？
- 王月出不出现如何有重量但不提前解释完？
- 老医师如何自然地给药？
- 刘承重是否仍给范野一条真正诱人的回头路？
- “众叛亲离”如何表现成多数人不愿付代价，而不是全员变坏？
- 第一章必须留下什么强问题让读者继续追？

开篇不能做：

- 少年履历表；
- 世界观说明书；
- 完整阴谋揭秘；
- 范野长篇价值宣言；
- 一口气解释“野”的郊野 / 民间 / 视野 / 分野 / 在野。

Issue #7 负责细化。

# P3 — 前史只按当前需要调取

原则：

> **回忆不是补背景，而是重新解释现在。**

每段前史写之前都问：

1. 它让读者重新理解当前哪个人？
2. 它让第一章哪个轻描淡写的事实变重？
3. 如果删掉，对当前主线有什么损失？

如果答案只是“读者终于知道设定”，就不写。

# P4 — 建立离宗后的真正主线

正文从这里开始彻底摆脱现实原型。

必须设计一个即使范野不存在也会发生的现实冲突。

冲突材料优先来自：

- 城池
- 商路 / 盐路 / 航线
- 药材与矿产
- 仓栈 / 商队
- 人质
- 情报
- 地方宗门的利益
- 外部势力的试探与合作

范野进入以后只改变原本正在运行的局，而不是让世界为了主角才开始动。

Issue #6 负责。

# P5 — 把“组织强大”写复杂

需要在事件中持续体现：

- 核心利益圈是最大收益者；
- 中层、普通弟子、部分百姓也可能得到真实好处；
- 很多人像被强制做了一笔买卖：得到一些，也失去一些；
- 少数人几乎只受害；
- 组织越集中，维持统一和征调的成本越高；
- 群众反应应同时存在：拥护、获利、忍耐、退出、躺平、阳奉阴违、偷改规则、藏人、公开反抗。

最终推动刘承重体系崩裂的不能只是一个英雄，而应有大规模“各自不再往同一方向使劲”。

# P6 — 第一批样章

Issue #8 当前建议三篇：

### A：范野离宗当天

验证开篇抓力、少解释、关系空缺与“野”的轻点。

### B：张之焘仍无名 / 刚崛起的一段前史

验证黑马身份、老医师关系，以及“邪狂”如何从具体选择长出来。

### C：王月出听见“现在就他自己”

验证不靠旁白解释痛苦，而靠失而复得的人生与最终不作为产生重量。

每篇都做：

> 初稿 → 砍至少 20% → 复读 → 记录删掉的废话类型。

# P7 — Beat Sheet 与正式写作

只有离宗后的第一条主线成立后，才拆未来 10–15 章。

每章记录：

1. 表面事件
2. 人物变化
3. 新增信息
4. 隐藏后果
5. 回忆是否必要
6. 删掉这一章损失什么

如果损失只是“一场挺好看的打斗”，优先考虑合并。

每完成 3–5 章复审一次，不为了“大纲正确”牺牲人物。

# Deferred — 暂时不要做

- 不提前固定六卷结构
- 不继续添加现实原型
- 不让现实乒乓事件规定正文后续
- 不冻结宗门最终制度
- 不决定张之焘最终生死
- 不用一次壮烈牺牲洗白王月出
- 不让龙默治理成为作者标准答案
- 不冻结“霸王拧”具体剑术机制
- 不把“霸王拧”写成价值观本身
- 不把老医师写成等待主角报仇的工具人
- 不提前拆上百章
- 不急着写最终大战

## 每轮复审

- 人物是在按自己的人生活，还是被大纲拖着走？
- 范野真的有多个成立选项吗？
- 张之焘是在让人看见，还是作者借他讲道理？
- 王月出的怯懦是否具体落在“失去什么”上？
- 龙默为什么适合承担，而不是作者需要一个接班人？
- 徐辰是不是太好用，开始替主角做主角该做的事？
- 群众是否被写成了同一种态度？
- 新武是否仍然真的强？
- 回忆是否重新解释现在？
- 彩蛋是否在服务小说？
- 读者首先感受到的是故事，还是作者观点？
