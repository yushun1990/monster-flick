## 总原则

不要按软件项目方式一次性拆完整部长篇。

当前采用：

> **人物做深 → 张之焘 / 范野两次离开做硬 → 天下狩猎开篇做实 → 外部世界先跑起来 → 长生秘法只做深层约束 → 只拆未来 10–15 章 → 写作 → 复审 → 滚动推进。**

最重要的纪律：

> **先把人养活。后面他们自己会惹事。**

同时遵守：

> **故事可以慢，但不能空。**

- [x] 范野不是江湖白痴；真正新问题仍是长期独自对抗整个社会信息网络。

## P4B 范野的路线：去看“不争”

当前强方向：

- [x] 范野不立即去找张之焘；

- [x] 这些宗门不是简单伪君子：思想可以是真的，组织利益与现实政治也是真的。
