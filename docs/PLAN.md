# 创作推进计划

## 总原则

不要按软件项目方式一次性把整部长篇拆完。

当前采用：

> **人物做深 → 《剑经》剑学做实 → 前史关系做实 → 验证“围杀开篇” → 建立离宗后的现实主线 → 只拆未来 10–15 章 → 写作 → 复审 → 滚动推进。**

最重要的纪律：

> **先把人养活。后面他们自己会惹事。**

当前大纲仍未完成。`OUTLINE.md` 只是 v2 结构方向，不是冻结骨架。

# P1 — 先把核心人物养活

当前人物组：

1. 范野
2. 张之焘
3. 王月出
4. 刘承重
5. 郴竹
6. 龙默
7. 徐辰
8. 老医师 / 药师
9. 俞大千（历史人物，体量可少但必须真实）

对应 Issues：#1–#5、#9，以及新增的《剑经》剑学任务。

## 每个人物至少回答

- 从哪里来？
- 过去真正失去过什么？
- 今天最舍不得什么？
- 真正想要什么？
- 什么事情能妥协，什么不能？
- 面对诱惑时有哪些真实可选项？
- 最不愿承认自己的哪一面？
- 如果范野不存在，他 / 她仍会怎样活？

人物卡不能停在“勇敢、聪明、善良、狂、稳”等标签。

验收标准：

> **给一个具体局面，不看大纲也大致知道这个人会怎么选，而且能解释为什么。**

# P1A — 《剑经》剑学做实

详细工作文档：`docs/SWORD_CLASSIC.md`。

必须回答：

- 俞大千究竟写了什么，为什么第一层真的适合启蒙？
- 为什么高阶剑客反而不再认真读？
- 《剑经》如何做到人人看得懂，却几乎没人真正读懂？
- 张之焘从一本到处都有的书里究竟读出了什么？
- 为什么必须靠天赋 + 大量真实交锋 + 活下来，不能靠口诀复制？
- 剑意如何体现“不断理解”而不是隐藏经验条？
- 剑宗正统剑气的物理 / 幻想规则是什么？
- 新秘法如何放大内力与剑气，而不是替旧体系开一个完全无关外挂？
- 《剑经》如何让弱内力者拥有越级杀人的可能，却不变成专门克制剑气的外挂？

### 正文纪律

《剑经》偶尔可以露一两句高度提炼的剑理，但必须：

1. 首先能讲剑；
2. 不能一次列出“人生十训”；
3. 后来若与范野的人生选择产生回声，由读者自己发现；
4. 正文绝不解释“这句话其实是在讲做人”。

# P1B — 上一代关系做实

## 张之焘

- 生于野，后来入宗；
- 不是少年成名，是后来的黑马；
- 家贫，长期只能接触廉价常见的《剑经》；
- 在外实战中反复重读，逐渐读出剑意；
- 因俞大千来到剑宗；
- 三胜王月出发生在不同阶段；
- 登顶后看见“正宗”内部复杂而体面的肮脏；
- 本来就准备离开，范野只是恰好在此时接住部分剑意与人生经验。

## 王月出

- 家族说大不大、说小不小；
- 张出现前是宗门顶级天才；
- 连输三次后逐渐被冷落；
- 是范野主动选择他为师；
- 范野成功后，他重新得到宗门信任、资源、地位、家族荣光和家庭稳定；
- 后期真正怕的是再次失去这些失而复得的一切。

## 龙默

- 与张、徐同代；
- 曾长期被王月出压到怀疑自己；
- 张这匹黑马让他意识到第一答案不是唯一答案；
- 最终找到自己的完整、稳定道路；
- 后期具备承担治理与现实残局的能力。

## 徐辰

- 与张、龙同代；
- 可以有地方商武家族背景；
- 天赋、武功、办事和人脉都“路子野”；
- 组织评价：**此人可用，不可大用。**

## 老医师

- 不是隐世高人，就是普通好人；
- 张无名时照常给他治伤；
- 张成名后态度不变；
- 后来成为范野长期固定医师 / 药师，关系亦师亦友；
- 范野离宗时只给药，不跟随；
- 后续被新贵日常羞辱时，不以“主角回来报仇”为主要功能。

# P2 — 验证正文围杀开篇

当前最强候选：**范野已经离宗，剑宗开始组织化围杀。**

可试第一句：

> **城郭之外谓之野。范野生在城里。**

然后他已经在城外，有人在杀他。

## 开篇必须完成

- 不靠旁白吹嘘，直接让读者看出范野为什么必须群杀；
- 追杀者不排队，不降智，是真的按“杀范野”设计战术；
- 范野已经为离宗失去装备、资源、身份或部分传承；
- 不一次解释离宗全貌；
- 王月出缺席先成为事实，前史以后再增重；
- 老医师的药可以成为离宗前最后留下的日常痕迹；
- 郴竹在围杀中再次出现并救范野是当前强候选；
- 第一章必须留下：他为什么走、宗门为什么非杀不可、郴竹为什么帮他。

开篇不能做：

- 少年履历表；
- 世界观说明书；
- 完整阴谋揭秘；
- 范野长篇价值宣言；
- 把郴竹写成专门报恩的工具性女主。

Issue #7 负责细化。

# P3 — 离宗代价设计

这个问题必须单独做，因为它直接触及“培养是否等于拥有”。

需要区分：

### 宗门确实有权收回的东西

- 身份；
- 公产兵器 / 装备；
- 药物与情报权限；
- 住处；
- 随从 / 陪练 / 医疗资源；
- 明确约定不得外带的某些传承。

### 开始越界的要求

- 要求摧毁已经成为范野身体与人生一部分的修为；
- 把二十多年训练成果整体解释为“宗门财产”；
- 以培养之恩主张对人的永久所有权。

具体方案暂不冻结，但必须让范野离开真的疼。

# P4 — 前史只按当前需要调取

原则：

> **回忆不是补背景，而是重新解释现在。**

每段前史写之前都问：

1. 它让读者重新理解当前哪个人？
2. 它让第一章哪个轻描淡写的事实变重？
3. 如果删掉，对当前主线有什么损失？

如果答案只是“读者终于知道设定”，就不写。

# P5 — 建立离宗后的真正主线

正文从这里开始彻底摆脱现实原型。

必须设计一个即使范野不存在也会发生的现实冲突。

优先材料：

- 城池
- 商路 / 盐路 / 航线
- 药材与矿产
- 仓栈 / 商队
- 人质
- 情报
- 地方宗门利益
- 外部势力试探与合作

范野进入以后只改变原本正在运行的局。

Issue #6 负责。

# P6 — 把“组织强大”写复杂

持续体现：

- 核心利益圈是最大收益者；
- 中层、普通弟子、部分百姓也得到真实好处；
- 很多人像被强制做了一笔买卖：得到一些，也失去一些；
- 少数人几乎只受害；
- 组织越集中，维持统一和征调的成本越高；
- 群众反应同时存在：拥护、获利、忍耐、退出、躺平、阳奉阴违、偷改规则、藏人、公开反抗。

最终推动刘承重体系崩裂的不能只是一个英雄，而应有大规模“各自不再往同一方向使劲”。

# P7 — 第一批样章

建议更新为：

### A：围杀开篇

验证范野绝顶高手的重量、组织化追杀、郴竹救援和“野”的轻点。

### B：张之焘第一次真正重新读懂《剑经》

不写升级提示，不解释太满。重点验证：一本人人看不起的启蒙书为什么在绝世天才经历生死以后突然变了。

### C：王月出听见“现在就他自己”

验证不靠旁白解释痛苦，而靠失而复得的人生与最终不作为产生重量。

每篇都做：

> 初稿 → 砍至少 20% → 复读 → 记录删掉的废话类型。

# P8 — Beat Sheet 与正式写作

只有围杀之后的第一条主线成立，才拆未来 10–15 章。

每章记录：

1. 表面事件
2. 人物变化
3. 新增信息
4. 隐藏后果
5. 回忆是否必要
6. 删掉这一章损失什么

每完成 3–5 章复审一次，不为了“大纲正确”牺牲人物。

## 每轮复审

- 人物是在按自己的人生活，还是被大纲拖着走？
- 范野真的有多个成立选项吗？
- 范野是否被写弱了，好让离宗后再升级？
- 张之焘的强来自绝世天赋 + 实战领悟，还是一本秘籍自动喂答案？
- 《剑经》首先还是剑学吗？
- 王月出的怯懦是否具体落在“失去什么”上？
- 龙默为什么适合承担，而不是作者需要一个接班人？
- 徐辰是不是太好用，开始替主角做主角该做的事？
- 郴竹有没有独立目标？
- 群众是否被写成同一种态度？
- 新武是否仍然真的强？
- 回忆是否重新解释现在？
- 彩蛋是否在服务小说？
- 读者首先感受到的是故事，还是作者观点？
