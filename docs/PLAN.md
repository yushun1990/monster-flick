# 创作推进计划

## 总原则

不要按软件项目的方式把整部长篇一次性拆完。

小说需要人物在推进中反过来改变剧情，因此采用：

> **先立创作边界 → 人物做深 → 人物反修大纲 → 第一卷做细 → 只拆未来 10–15 章 → 写作 → 复审 → 再滚动推进。**

当前最重要的纪律：

> **停止继续添加大事件。先把已有东西做深。**

同时再次强调：**当前大纲没有完成。** `OUTLINE.md` 只是 v0 灵感结构，不是要维护的既定骨架。

---

# P0 — 小说宪法 / 创作边界

目标：固定不可轻易违反的创作规则，但不冻结剧情骨架。

## 完成标准

- [x] 核心价值底色明确：人的不可占有性
- [x] 核心开放问题明确：组织若靠剥夺个体换来强大，那么强大的目的是什么
- [x] “霸王拧”精神方向明确，但具体剑理不冻结
- [x] 密功基本限制明确
- [x] 主角战斗逻辑方向明确
- [x] 不数值化境界
- [x] 不系统 / 不穿越 / 不神器救场
- [x] 新武是真的强
- [x] 王月出不能简单洗白
- [x] 郴竹必须独立成立
- [x] 刘承重不能写成“方向错了的好人”
- [x] 外部世界必须存在自己的利益与历史
- [x] 叙事强调高信息密度、低解释、冷幽默顺带发生
- [x] 作者可以倾向个人自由 / 个人意志，但不能替读者宣布标准答案
- [x] 现实梗只能寄生在有效剧情上，不能让剧情替梗搭台

P0 主要产物：`docs/STORY_BIBLE.md`、`docs/INSPIRATIONS.md`

# P1 — 五名核心人物

目标：暂时不继续编大事件，只把人物做透。

顺序：

1. 范野
2. 张之焘
3. 王月出
4. 刘承重
5. 郴竹

## 每个人物必须回答

### 身份层

- 他 / 她从哪里来？
- 家庭 / 师承 / 早年经历是什么？
- 靠什么获得今天的位置？
- 在别人眼中是什么样？

### 欲望层

- 真正最想要什么？
- 嘴上说想要什么？
- 两者是否一致？

### 恐惧层

- 最怕失去什么？
- 什么代价绝不愿支付？

### 自我认知

- 最不愿承认自己是什么样的人？
- 如何替自己不光彩的选择辩护？

### 边界

- 什么事情上可以妥协？
- 什么事情上绝不妥协？

### 关系债务

- 欠另外四个人什么？
- 另外四个人欠其什么？
- 这些“债”什么时候发生变化？

### 人物弧

- 开篇时相信什么？
- 中段什么事实击碎这种相信？
- 最后变了，还是坚持到了底？

## P1 完成标准

人物卡不能写成：

> “勇敢、正直、善良、聪明。”

而要做到：

> **给他 / 她一个具体局面，不看大纲也大致知道会怎么选。**

# P2 — 二级人物与外部势力

核心人物稳定后再做。

## 人物

- 龙默
- 徐辰
- 孙小莎
- 王青川
- 老医师
- 齐门核心人物
- 海东至少 3 名有独立利益的人物
- 高丽至少 2 名长期老对手
- 西洲至少 3 名与范野流亡阶段有关的人物

## 势力

每股势力至少回答：

- 主要资源是什么？
- 主要恐惧是什么？
- 为什么与其他势力合作 / 敌对？
- 内部有哪些派系？
- 如果范野不存在，他们仍然会做什么？

最后一条尤其重要，用来判断这个世界是不是只围绕主角运转。

# P3 — 世界运行规则

不是做百科全书，而是只补剧情真正需要的结构。

## 需要明确

- 天衡宗如何管理地方势力
- 城池 / 商路 / 盐路 / 药材 / 矿山与武林势力的关系
- 情报如何传播
- 高手为什么值得一个组织投入巨额资源
- 朝廷或世俗政权与江湖的关系
- 海东 / 高丽 / 西洲之间的基本交通与利益链
- 医药体系与伤病恢复的现实约束
- 神兵为何稀缺
- 《养元诀》传播为什么会形成结构性优势

## 不需要明确

- 完整世界地图每个村镇
- 武学全部等级
- 所有门派名称
- 每一种功法机制
- 《归元长生经》的唯一来源真相

原则：

> **只做水下冰山，不把冰山全端上桌。**

# P4 — 第一卷结构设计

第一卷要独立好看。

禁止依赖：

> “熬过前五十章，后面大阴谋就来了。”

## 第一卷必须完成

- [ ] 用一件具体的真实斗争直接开局
- [ ] 范野以“已经很强”的状态登场
- [ ] 展示武功并非解决所有问题
- [ ] 建立王月出与范野的真感情
- [ ] 引出张之焘，但不揭完整历史
- [ ] 郴竹进入并拥有独立目标
- [ ] 至少展示一股外部势力的真实利益
- [ ] 暗示《养元诀》异常，但不解释
- [ ] 第一卷自身有一个完整高潮与结局
- [ ] 卷末人物关系发生不可逆变化

## 第一卷暂定不可逆变化

- 范野第一次真正走出王月出的武学路径
- 范野开始怀疑宗门关于张之焘的叙事
- 王月出意识到弟子正在脱离自己能够控制 / 指导的范围
- 范野与郴竹真正建立认可

---

# P5 — 第一批章节 Beat Sheet

第一卷结构确定后，只拆未来 10–15 章。

每章 / 场景必须标记：

1. **表面事件**：这一章发生什么？
2. **人物变化**：谁对谁的判断变了？
3. **新增信息**：读者比上一章多知道了什么？
4. **隐藏后果**：哪件事以后会回来？
5. **删减检查**：这章如果删掉，损失什么？

如果答案只是：

> “少了一场挺好看的打斗。”

则优先考虑合并。

# P6 — 文风样章

先写 3 个不同场景，不直接承诺为正式第一章：

### 样章 A：范野第一次正式出场

目标：验证“高手无需吹”的写法。

### 样章 B：范野与张之焘第一次真正交手

目标：验证冷幽默、少废话、武学观的呈现。

### 样章 C：政治 / 宗门场景

例如王月出从旁人口中得知“现在就他自己”。

目标：验证少解释、靠细节承担情绪的能力。

## 样章复审指标

- 有没有作者为了搞笑硬塞对白？
- 有没有“作者告诉读者这个人很聪明”而不是让人物做出来？
- 有没有纯装饰细节？
- 有没有段落只有一种功能？
- 有没有解释本应由读者自己理解的潜台词？
- 有没有为了现实彩蛋、谐音梗单独搭戏？
- 是否过度模仿某位具体作者的句法，而没有形成自己的叙述声音？

---

# P7 — 第一卷正式写作

采用滚动式推进。

每完成约 3–5 章：

1. 检查人物有没有被大纲强迫；
2. 检查节奏；
3. 检查场景密度；
4. 检查秘密是否泄露过早；
5. 更新后续 10–15 章 beat sheet；
6. 必要时修改大纲，不为了“大纲正确”牺牲人物。

---

# P8 — 第一卷完成后复盘

不立即开始第二卷。

先回答：

- 范野真的活了吗？
- 张之焘是否只是“狂人设定”？
- 王月出是否足够真实，还是已经开始工具化？
- 郴竹是否可以从小说中抽出来单独成立？
- 刘承重是否出现过早 / 解释过多？
- 外部世界是否让人觉得在主线之外仍然运行？
- 《养元诀》的诱惑是否足够真实？
- 第一卷即使没有后续卷，是否仍然值得看？

通过后再推进第二卷。

# 写作过程中的红线

出现以下迹象时立即停下来复审：

- “突然突破一个境界解决问题”
- “反派明明能杀却为了废话不杀”
- “所有配角都在讨论主角”
- “为了让主角聪明，对手集体变蠢”
- “解释完整阴谋给读者听”
- “女主的任务变成理解 / 鼓励男主”
- “外部势力只是换皮外国队”
- “幽默开始依赖角色贫嘴”
- “为了塞现实彩蛋破坏小说逻辑”
- “为了露谐音梗专门造一个无用场景”
- “一场打斗打了很多章但人物与局势没有变化”
- “作者开始舍不得删自己觉得漂亮的句子”
- “作者开始把自己的价值倾向写成读者必须接受的标准答案”
