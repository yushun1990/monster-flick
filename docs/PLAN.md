# 创作推进计划（当前版）

> 最新总 canon：[`CANON_CURRENT.md`](CANON_CURRENT.md)
>
> 本计划只管“接下来做什么”，不承担人物设定归档职责。

---

## 总原则

不要按软件项目方式一次性拆完整部长篇。

当前采用：

> **人物做深 → 张之焘 / 范野两次离开做硬 → 天下狩猎开篇做实 → 外部世界先跑起来 → 长生秘法只做深层约束 → 只拆未来 10–15 章 → 写作 → 复审 → 滚动推进。**

最重要的纪律：

> **先把人养活。后面他们自己会惹事。**

同时遵守：

> **故事可以慢，但不能空。**
