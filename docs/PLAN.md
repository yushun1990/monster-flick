# 创作推进计划

## 总原则

不要按软件项目方式一次性把整部长篇拆完。

当前采用：

> **人物做深 → 张之焘 / 范野离宗因果做实 → 天下狩猎开篇做实 → 外部世界先跑起来 → 长生秘法只做深层约束 → 只拆未来 10–15 章 → 写作 → 复审 → 滚动推进。**

最重要的纪律：

> **先把人养活。后面他们自己会惹事。**

当前大纲仍未完成。`OUTLINE.md` 只是 v3 结构方向，不是冻结骨架。

- 从哪里来？

# P1A — 张之焘被逐与“天下问题”做实

这是目前最高优先级前史之一。

需要完成：

## 玄清宗七剑

- 二流门派玄清宗二长老到底做了什么；
- 为什么玄清宗内部认为事情已经处理；
- 张怎样偶然接触到那家贫民 / 流离失所的孩子；
- 为什么张最终决定一人上门；
- “七剑斩二长老”如何写得技术上可信，不变成技能动画；
- 最后一剑保留 Dota1 剑圣式凌空下劈的视觉狠劲，但动作必须在本书剑术里成立；
- 玄清宗掌门为什么手握剑柄却不拔，而不是被剑意定身。

## 剑宗为什么能借此逐张

公开理由必须成立：

- 擅闯他宗；
- 私杀长老；
- 越过既有处置；
- 破坏宗门间秩序；
- 私人裁决不可复制为共同规则。

必须允许有真正正直的人反对张，而不是全员坏人。

深层原因则是：张不断干扰刘承重多年推进的秘密计划，并让剑宗内部原本已经翻涌的矛盾突然显形。

## 张离开后如何被改写

- 从“剑宗异类”到“危险人物”再到“天下问题”；
- “俞大千失落真剑谱”传闻如何自然长出来 / 被剑宗推动；
- 当前倾向所谓真本根本不存在；
- 刘承重不在乎真假，只在乎让江湖不同人按自己的欲望靠近张。

## 不同势力为什么对张态度不同

- 散修 / 剑痴：想赌一步登天；
- 中小门派：更怕张本人不可预测，希望除掉并换剑宗人情；
- 大宗门：更重视张本人作为战略资产，可能想结盟、借势、庇护、抓活；
- 大宗门也怕张，因为他无法真正被拥有。

# P1C — 范野离宗代价

这个问题必须继续设计，但当前已经排除错误答案。

## 宗门有权收回

- 名剑 / 公产兵器；
- 身份牌、职印、权限；
- 宅院、坐骑、俸禄；
- 药物、情报、陪练、医疗支持；
- 明确属于宗门秘密且约定不得外传的传承；
- 范野也可以承诺不带走部属 / 弟子。

## 当前否决

- 自废修为；
- 把二十多年身体、经验、个人剑意整体算成宗门财产；
- “挨三掌 / 废三成功力”这种方便但机械的离宗仪式。

## 真正要回答

- 范野如何承认剑宗养育之恩而仍然离开；
- 为什么这笔账本来就不可能“两清”；
- 离开时还有什么真实身体 / 现实代价；
- 是否让他在此前重要外部任务里已经负伤，从而以不全盛状态进入狩猎。

核心：

> **恩不能自动变成所有权。**

# P1E — 长生秘法只做“深层约束”，不抢前台

详细工作文档：`docs/LONGEVITY_METHOD.md`。

当前强方向：

- 刘承重很早发现秘法，也很早就想要长生；
- 修炼需要多年准备：稳定宗门、候选人、实验、资源、医疗、保密；
- 新法本身真强，把人逐渐变成高效率资源加工器；
- 工作术语“本元”：高速转化资源需要消耗身体深层恢复 / 修补余量；
- 刘培养很多天才、小幅抽取，避免出现整代统一短命的统计 bug；
- 接近危险线的人退休、静养、转任；极少数才被安排到真正高风险秘密任务；
- 核心圈靠体系获得财富、权力、武力与更长强盛期，同时失去退出能力；
- 刘最终可以在特定条件下彻底抽取核心服务者，但不能隔空念咒随便杀人；
- “天才”标准从剑道天赋逐渐偷换成资源转化效率，两者相关但不线性。

最重要：

> **前台写权力，中层写制度和利益，深层才写秘法。**

# P2 — 验证“移动狩猎”开篇

当前开篇不再是剑宗预设统一围杀地点。

可试第一句：

> **城郭之外谓之野。范野生在城里。**

随后范野已经离开，整个江湖开始追踪他。

## 刘承重的局

- 故意让范野离宗 / 状态不佳成为可确认消息；
- 推动“张把失落真剑谱传给范野”的传闻；
- 仇家来杀；
- 各大势力来抢活人；
- 大势力不能公开承认抢人，所以蒙面和互相误判成立；
- 剑宗自己远远跟着，等待各方先耗；
- 最后再下场杀范、重创其他势力核心。

## 开篇必须完成

- 不靠旁白吹嘘，直接让读者看出范野为什么值这么多人动；
- 各方聪明，不排队送死；
- 追逐是移动的，会经过道路、城镇、渡口、势力边界；
- 王月出缺席先成为事实；
- 老医师的药可成为离宗前最后的日常痕迹；
- 不揭刘承重完整长生计划；
- 不一次讲完张之焘前史。

# P2A — 龙默 / 徐辰：怎样逼剑宗提前下场

这是目前开篇最大的技术难点之一。

目标：

> **破坏刘承重一直站在棋盘外坐收渔利的能力。**

约束：

- 龙默绝不亲自到现场；
- 不能直接泄露具体秘密；
- 徐辰不能发万能密信；
- 外部大派必须靠自己的聪明与情报系统从蛛丝马迹推理；
- 龙、徐甚至可以不共谋；
- 两人不需要预见郴竹；
- 最终必须制造“剑宗再不下场，范野真的会脱离控制”的局面。

要围绕移动狩猎重新设计，不再依赖固定逃生路线 / 固定山谷。

# P2B — 郴竹开篇位置

当前强候选：

- 郴竹所属大势力也是来抢范野的；
- 她不是核心执行者，只负责外围警戒，甚至不知道目标是谁；
- 少年范野与她只有一次很轻的好印象：范野看见她一个聪明小动作，随口说“挺聪明”；
- 不是救命恩、让赛、旧债，也不是多年暗恋；
- 她认出重伤范野时，先有“不能让他死”的判断；
- 她靠临场信息判断和误导各派救人，而不是二打多正面杀穿；
- 最好没人知道她救走范野，包括她自己的宗门；
- 她要付出真实代价：离岗、受伤、令牌 / 信号受损、被问责等；
- 可以保留最后一小段两人浴血突围，但只是走完已经被智慧撕开的缝。

# P3 — 外部天下先跑起来

这是防止秘法线过早露底的关键。

必须设计即使范野不存在也会发生的真实冲突。

优先材料：

- 城池；
- 商路 / 盐路 / 航线；
- 港口 / 渡口；
- 药材与矿产；
- 仓栈 / 商队；
- 人质；
- 情报；
- 地方宗门利益；
- 外部战争；
- 旧盟约失效；
- 其他大宗门自己的改革。

刘不必制造所有危机。他更擅长利用真实危机：集中权力、推动新法、统一资源。

范野在宗门时期也应一直有真正重要的外部任务，让内部异常始终只是背景碎片。

创作结构：

> **外部天下负责横向把故事往前推；剑宗内部异常负责纵向往深处沉。**

Issue #6 负责。

# P4 — 前史只按当前需要调取

原则：

> **回忆不是补背景，而是重新解释现在。**

每段前史写之前都问：

1. 它让读者重新理解当前哪个人？
2. 它让第一章哪个轻描淡写的事实变重？
3. 如果删掉，对当前主线有什么损失？

如果答案只是“读者终于知道设定”，就不写。

---

# P5 — 把“组织强大”写复杂

持续体现：

- 核心利益圈是最大收益者；
- 中层、普通弟子、部分百姓也得到真实好处；
- 很多人像被强制做了一笔买卖：得到一些，也失去一些；
- 少数人几乎只受害；
- 新法真强，受宠天才真能打；
- 资源投入和战绩会反过来证明组织选择“正确”；
- 越来越多人学会把活人看成资质、产出、损耗与可调配对象；
- 群众反应同时存在：拥护、获利、忍耐、退出、躺平、阳奉阴违、偷改规则、藏人、公开反抗。

最终推动刘承重体系崩裂的不能只是一个英雄，而应有大规模“各自不再往同一方向使劲”。

# P6 — 第一批样章

### A：移动狩猎开篇

验证：

- 范野绝顶高手的重量；
- 没有统一伏击地点的追逐感；
- 不同势力不同目标；
- 剑宗坐收渔利的算盘；
- 郴竹外围位置与第一次真正救援；
- 龙 / 徐的暗中搅局只露结果，不解释全貌。

### B：玄清宗七剑

验证：

- 张之焘为什么会让中小门派真正害怕；
- 二长老该死和私人裁决危险可以同时成立；
- 最后一剑的凌空下劈视觉；
- 玄清掌门不拔剑的心理重量；
- 这件事为什么足够成为剑宗逐张的公开理由。

### C：王月出听见“现在就他自己”

验证不靠旁白解释痛苦，而靠失而复得的人生与最终不作为产生重量。

### D（可选）：某个新一代“天才”被评定

只在需要验证剑宗风气变化时写。

场景表面讨论天赋、资源、培养路线；读者只隐约感觉宗门评价标准与真正剑道天赋有点错位，不揭长生秘法。

每篇都做：

> 初稿 → 砍至少 20% → 复读 → 记录删掉的废话类型。

# P7 — Beat Sheet 与正式写作

只有开篇狩猎与第一条外部真实冲突成立，才拆未来 10–15 章。

每章记录：

1. 表面事件
2. 人物变化
3. 新增信息
4. 隐藏后果
5. 回忆是否必要
6. 秘法异常是否过于显眼
7. 外部世界是否仍在推进
8. 删掉这一章损失什么

每完成 3–5 章复审一次，不为了“大纲正确”牺牲人物。

# Deferred — 暂时不要做

- 不提前固定六卷结构
- 不继续添加现实原型
- 不让现实乒乓事件规定正文后续
- 不冻结宗门最终制度
- 不决定张之焘最终生死
- 不用一次壮烈牺牲洗白王月出
- 不让龙默治理成为作者标准答案
- 不把《剑经》真正写成山洞失传宝典
- 不把剑意写成经验条
- 不把范野离宗写成自废修为
- 不把开篇重新缩回固定围杀点
- 不让龙默现场救人
- 不让郴竹靠正面武力完成整场救援
- 不让长生秘法过早成为小说唯一谜题
- 不提前拆上百章
- 不急着写最终大战

## 每轮复审

- 人物是在按自己的人生活，还是被大纲拖着走？
- 范野真的有多个成立选项吗？
- 范野是否被写弱了，好让离宗后再升级？
- 张之焘的强来自绝世天赋 + 实战领悟，还是一本秘籍自动喂答案？
- 玄清宗事件里反对张的人有没有真正成立的道理？
- 整个江湖是否被写成只会抢秘籍的 NPC？
- 《剑经》首先还是剑学吗？
- 王月出的怯懦是否具体落在“失去什么”上？
- 龙默是不是又被写成了暗夜救主？
- 徐辰是不是太好用，开始替所有聪明人完成推理？
- 郴竹有没有独立目标？
- 郴竹救范是否依赖大恩 / 报恩？
- 新武是否仍然真的强？
- “天才 = 转化效率”的变化是否只作为隐约制度味道存在，而没有提前泄底？
- 外部世界本章有没有继续运行？
- 回忆是否重新解释现在？
- 读者首先感受到的是故事，还是作者观点 / 邪功说明书？
