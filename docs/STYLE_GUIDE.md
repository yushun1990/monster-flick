# 叙事风格与写作纪律

> 本文记录正文与讨论时的长期风格约束。核心参照之一是冰临神下式的冷、密、狠，但不把风格理解成表面古雅、故作阴沉或堆机锋。

## 1. 最重要的一条

> **故事可以慢，但不能空。**

一段对话、一个动作、一个场景最好同时承担两件以上的事：推进事件、暴露关系、改变判断、留下信息差、制造后果。

禁止为了“气氛”写大段没有新信息、没有选择、没有后果的废话。

## 2. 不替人物解释自己

正文尽量少写：

- “其实她心里……”；
- “她理智上明白……”；
- “这说明……”；
- “她真正想要的是……”。

优先让行为自己说明。

例如一个人因为私人感情故意把一条范野行踪卖给剑宗，换回一项她本来根本看不上眼的利益；读者应从交易本身看懂她的恶意，不需要旁白替她做心理总结。

## 3. 聪明不是万能

聪明人不能靠智力把所有人安排得舒舒服服。

政治需要：

- 利益；
- 威胁；
- 欺骗；
- 妥协；
- 流血；
- 有时是死人。

真正强的谋略不是“所有人喝茶露面就自动按计划行动”，而是知道谁会付代价、谁不会低头、失败时怎么继续活。

高手、天才、好人都可以在政治中陨落。

## 4. 人物允许不讲道理

聪明、清醒、深谋远虑，不等于情绪健康。

人物可以同时：

- 知道某人无辜；
- 仍然讨厌他；
- 知道自己的迁怒没有道理；
- 仍然让他付出真实代价。

这种矛盾不要急着调和。

尤其女人不能因为进入感情线就自动变软、变可爱、变成负责理解所有人的成熟角色。

## 5. 阴谋从行动里长出来

不要先宣布“这是一个大阴谋”。

先写：

- 一笔本来不值得做的交易突然成交；
- 一条消息恰好被该知道的人知道；
- 某个高手的路线忽然被咬准；
- 某批人无声消失；
- 某个看似合理的命令多偏了半寸。

后果出现以后，读者再慢慢意识到前面的东西原来连在一起。

## 6. 幽默纪律

正文和创作讨论都不要靠自以为幽默撑气氛。

可以有笑，但应来自：

- 人物性格；
- 信息差；
- 冷处理；
- 荒谬现实；
- 一本正经的人做出符合自身逻辑、却令人发笑的事。

禁止：

- 满篇段子；
- 每两段一次包袱；
- 作者替读者吐槽；
- 为了显得轻松不断加网络梗；
- 用玩笑冲淡本来应该有重量的政治、死亡和关系冲突。

## 7. 对话纪律

对话要短，但不能只是“酷”。

一句话最好同时有表层意思和关系作用。

人物不会把自己的完整动机解释给对方，也不会替读者做人物分析。

真正重要的话可以很普通；重要的是说话之前发生了什么、对方知道什么、说完以后谁必须改变行动。

## 8. 世界观纪律

> **不要让我看见机制，让我直接相信这个世界本来就在这里。**

宗门、商路、地盘、药材、渡口、情报、人情、武功与制度都应通过人物正在做的事情自然出现。

设定只在它改变选择和代价时进入正文。

黑魔法、封印、长生机制尤其不能抢前台。前台永远先是人、权力、江湖与具体生活。

## 9. 风格校验

写完一段后问：

1. 删掉一半心理解释，事情还能不能成立？
2. 这一段除了“好看”之外改变了什么？
3. 人物是不是因为作者需要而突然变笨？
4. 聪明角色是不是又靠嘴把政治问题说没了？
5. 有没有为了显得有趣而把危险人物写成段子人？
6. 有没有把爱情写成替人物洗掉狠、偏执和利益？

如果有，重写。

## 10. 当前人物特别提醒

- **郴竹**：老江湖、判断通透，不擅长层层阴谋不等于不聪明；她常常凭经验和直觉先看见危险的本质。
- **小师妹**：聪明、狠、能忍；不是高情商管理者。她的政治会死人，她对郴竹的依赖可以很深、很不健康，私人恶意可以借公事真正伤人。
- **范野**：不是谁的兵，也不是任人调度的“顶级人才”。他真正危险之处是很难被组织长期握住。
- **刘承重**：不要让邪功替他负责。他先有占有与控制，秘法只是把这套逻辑推到身体层面。

总的目标不是“像某种文风的句子”，而是：

> **人物做出的事情够真，后果够硬，作者少替他们说话。**
