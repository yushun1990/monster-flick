# 太平殿专项设定（当前 Canon）

> 状态：当前强 canon。
>
> 本文负责中州地下江湖中著名杀手组织“太平殿”的定位，以及它与《天下狩猎》、荒庙—芦苇荡反猎、范野离开中州之间的关系。
>
> **“太平殿”名称正式锁定。**
>
> **“中州”目前只是剑宗主要经营区域及其周边江湖板块的暂用地名，地理范围、正式名称与行政 / 江湖边界尚未最终锁死。**

---

# 1. 名称：太平殿

正式名称：

> # **太平殿**

名字的出发点不是阴曹地府，也不是“血、鬼、无常”一类杀手组织惯用的阴森命名。

它的核心意味来自：

> **替天行道。**

太平殿对自己所做之事可以有一套相当体面的历史解释：世间总有无法由官府、宗门、家族、商会公开处理的人与事；有人该死，有事该平，于是有人替天收人，替世间“平事”。

因此“太平”既有正面的秩序意味，又天然带着一层冷意：

> **人死了，事平了。**
>
> **事平了，也就太平了。**

这种自我解释不要求太平殿成员人人真心相信“正义”。它首先是一套存在多年以后自然形成的组织传统、行话与体面叙事。

名称不能写成单纯反讽段子。正文应让“太平殿”本身先具有真实威望与历史重量，冷幽默由局势自然长出来。

可保留的江湖话外音：

> **太平殿这回，可不太平了。**

这句话是强候选，不要求必须原样出现在正文。

---

# 2. 太平殿在中州的位置

当前锁定：

> **太平殿是中州最有名、最有分量的职业杀手组织之一；在很多江湖人的认知里，它甚至就是中州最著名的那一家。**

避免做硬排行榜，不需要宣布“天下第一杀手组织”。

它能长期存在，说明它绝不只是几十个会杀人的亡命徒临时抱团，而是一套成熟地下生意：

- 接单；
- 情报；
- 盯梢；
- 搜索；
- 路线封锁；
- 接头与联络；
- 补给；
- 清场；
- 专业刺杀；
- 必要时处理尸体、证据与善后。

正式组织结构、总部、分舵、席位、内部规矩、报酬体系目前不锁死。

“大统领”是太平殿在此次范野任务中的高层 / 高级行动头领，但不等于整个太平殿唯一最高首领。

大统领身边两名副手同样是中州江湖叫得出名号的狠角色。

---

# 3. 太平殿不是刘承重的私人家奴

这一点与 `TIANXIA_HUNTING.md` 既有两层杀网保持一致。

> **刘承重手里的刀，并不全摆在剑宗名册上；但不摆在剑宗名册上的刀，也不等于全是刘承重私人养出来的。**

太平殿是独立存在的地下组织。

刘承重一方通过既有黑线、核心圈长老及可能存在的固定中间人，能够出钱、调动关系、委托或长期合作，但刘承重本人不亲自下场谈价、传日常命令。

所以范野最初与太平殿发生冲突时，本质仍然是一桩由刘承重一方推动的杀人生意。

但芦苇荡以后事情发生变化。

---

# 4. 荒庙与芦苇荡：一桩生意变成太平殿自己的血债

荒庙节点及老鬼、大统领一线，当前正式归入太平殿相关行动网络。

荒庙仍然只是一个节点，不代表太平殿全部力量都聚集在那里。

第一夜，范野利用黑暗、视野与突然性杀穿荒庙节点，大量职业杀手死亡，老鬼等极少数人逃走。

老鬼随后向大统领报信。

第二日鱼肚白，大统领带两名成名副手及更多高手赶到。

随后发生：

> **三人倒，三人伤，三人消失。**

大统领与两名副手第一时间追出，最终带人进入芦苇荡。

从清晨到近黄昏，双方进行一整天真正的猎人与猎人互猎。

最终当前锁定：

> **追入芦苇荡的太平殿杀手全部死掉，包括大统领与两名副手。**

老鬼最终是否也死在其中，仍由正文连续性决定。

这意味着事情已经不能只理解成：

> 刘承重出钱，太平殿接了一单，任务失败。

因为太平殿在中州有名望、有同行威信、有自己的人与规矩。

当大统领、两名成名副手及一大批核心高手被范野杀死以后，太平殿自己也产生了一笔无法忽略的账。

> **刘承重买范野的命，是一笔账。**
>
> **太平殿死在范野手里这么多人，是另一笔账。**

两笔账可以重合，但不能混为一谈。

因此即使某一刻刘承重一方想降低投入，太平殿也未必会立刻把这一切当成普通“买卖失败”揭过去。

具体追偿方式、是否继续立即加码、内部谁主张报仇谁主张止损，暂不锁死。

# 5. 《迟也，妄也，不可回！》的第二层“不可回”

芦苇荡章节正式章名仍为：

> # **《迟也，妄也，不可回！》**

《剑经》中的直接含义仍是“机”：

> **动已见，迟也；动未见，妄也；取其不可回，是谓机。**

但本章的“不可回”同时承担一个更大的故事回响。

这里的“不可回”**不是指范野单纯回不了剑宗山门**。

当前真正指向的是：

> **芦苇荡这一日以后，范野已经很难再回中州。**

原因不是抽象的“恩断义绝”，而是非常具体的死人与现实后果：

- 数月天下狩猎已经使他与剑宗关系无法恢复到从前；
- 荒庙一夜杀掉太平殿大量高手；
- 芦苇荡又杀死大统领、两名成名副手及整批追兵；
- 太平殿从受雇杀人者变成拥有自己血债的独立仇家；
- 中州原本熟悉的社会节点、江湖关系和地下秩序，对范野越来越危险。

所以范野接下来继续向外走，不只是作者需要把他送入道家宗门板块。

> **他身后的中州正在越来越没有容身之地。**

“不可回”因此同时存在三层：

1. **剑上不可回**：真正的“机”是对方已经作出无法收回的动作 / 选择；
2. **杀局不可回**：范野在荒庙本有机会拿钱、药、剑后离开，却主动留下等援兵，自己选择把这场反猎继续下去；
3. **中州不可回**：芦苇荡一天死得太多，尤其太平殿这一线被打得太狠，范野已经无法再像过去那样留在或返回中州。

这里的“中州不可回”不是宇宙法则，也不是说范野一生绝不能再次踏入中州。

后期若局势、身份、力量结构发生巨大变化，他当然可能回来。

它指的是当前《天下狩猎》阶段：

> **原来的中州，已经回不去了。**

# 6. 当前仍未锁死

- “中州”是否为最终正式地名；
- 中州具体地理范围、州郡 / 江湖板块关系；
- 太平殿建立年代与历史源头；
- “替天行道”是创立时明确宗旨，还是后世形成的组织体面叙事；
- 太平殿总部位置；
- 太平殿内部完整层级；
- 大统领正式姓名、绰号与精确职位；
- 两名副手正式姓名、武功与过往；
- 老鬼在太平殿中的正式层级；
- 太平殿与剑宗黑线合作已持续多少年；
- 芦苇荡损失在太平殿整个组织中究竟占多大比例；
- 太平殿在芦苇荡后如何追责、报复、止损或重估范野；
- “太平殿这回，可不太平了”是否最终进入正文。
