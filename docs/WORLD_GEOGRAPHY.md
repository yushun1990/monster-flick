# 天下地理（当前强 Canon）

> 状态：当前强 canon。
>
> 本文只负责天下最高层级地理框架。州郡、城市、水系、山川、行政边界、宗门经营区和具体商路后续逐步补全。

---

# 1. 五大地理 / 江湖板块

当前正式锁定天下分为五个大板块：

1. **中州**
2. **东土**
3. **西域**
4. **南洋**
5. **北海**

这五个名字首先是天下人长期形成的宏观地理、交通、文化与江湖认知，不要求像现代行政区一样拥有刀切般精确的边界。

板块交界处可以存在模糊地带、跨区商路、混合文化和多方长期经营区。

---

# 2. 当前已锁宗门位置

- **剑宗：中州。**
- 剑宗在中州内部的地理位置相对偏南。
- **逍遥峰：东土。**

其他重要宗门与势力的板块位置以后根据故事需要逐步落图，不提前为了填地图而填地图。

---

# 3. 与《天下狩猎》的直接关系

范野在《天下狩猎》后期原本没有前往东土或逍遥峰的计划。

当前锁定：

> **他本来向南逃。**

原因很现实：剑宗位置偏中州南部，继续向南可以更快离开中州，进入南洋板块。

所以范野当时真正的目标只是：

> **先离开中州。**

进入南洋以后怎么办，可以以后再想。

他后来之所以转而进入东土，是芦苇荡之后天下各方抢夺失控、桥上坠江、被中州—东土东行货船意外捞起造成的命运偏航。

详细 canon 见 `RIVER_ESCAPE.md`。

---

# 4. 当前明确废弃

以下旧方向不再使用：

- 范野因为想亲眼看看“无为 / 不争 / 清静 / 逍遥”而主动规划东土路线；
- 范野主动把逍遥峰或东土道家宗门当作离宗后的目的地；
- 为了让范野遇见逍遥峰，提前把他的个人游历路线强行指向东土。

东土不是范野自己选中的下一站。

> **他本来往南，最后被天下这一场乱局打到了东边。**
