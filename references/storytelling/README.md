# Storytelling Reference Library

这里保存用于研究“怎样把故事讲得自然、可信、好看”的参考材料索引与分析。

本目录不是文风模仿库，也不是作品全文收藏库。目标是从用户真正喜欢的小说片段中提炼可迁移的叙事规律，逐步形成 `skills/fiction-writing/SKILL.md`。

## 使用原则

1. **优先保存来源信息与分析，不保存整本版权作品。**
2. 可以保存为分析所必需的有限片段；若原文较长，优先记录书名、章节、链接和定位说明。
3. 用户不需要先解释“为什么喜欢”。只有明确感受时再补一句即可，例如：
   - 对话特别自然；
   - 明明没发生大事却很好看；
   - 人物一出场就立住了；
   - 转折突然但不生硬；
   - 打斗很短却很有力量。
4. 分析时关注可迁移机制，不总结成“像某位作者”。
5. 稳定规律经过多个样本和正文实践验证后，才提升进 fiction skill。

## 建议目录

```text
references/storytelling/
├── README.md
├── TEMPLATE.md
├── binglinshenxia/
│   ├── daming-yaonie/
│   └── siren-jing/
├── other-authors/
└── notes/
```

Git 不保存空目录；对应作者或作品的目录会在第一个样本加入时自然生成。

## 分析维度

不要求每个样本覆盖全部维度，只分析真正有价值的部分：

- 场景如何开始、如何结束；
- 人物为什么在这一刻做这件事；
- 对话的眼前目的与潜台词；
- 信息什么时候给，什么时候忍住；
- 普通日常为什么仍然可读；
- 时间如何跳过而不显得赶；
- 人物关系怎样自然变化；
- 环境如何进入故事，而不是成为设定说明；
- 冲突如何升级；
- 打斗里哪些动作值得写、哪些被省略；
- 幽默如何从人物逻辑和处境自然产生；
- 哪些地方容易被 AI 写成“任务执行感”。

## 与小说 Canon 的关系

本目录只研究叙事方法，不定义 `monster-flick` 世界事实。人物、世界、情节强 Canon 仍以 `docs/` 为准。
