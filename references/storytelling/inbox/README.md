# Storytelling Inbox

这里是最省事的投递入口。

用户看到喜欢的小说片段后，可以直接在本目录新增一个 Markdown 文件，不需要预先分类，也不需要分析。

最低格式甚至只需要：

```md
# 随便起个名字

来源：书名 / 章节 / 链接（知道多少写多少）

我喜欢这段。（可选，不知道为什么喜欢也没关系）

> 参考片段或定位说明
```

之后由 ChatGPT 负责：

1. 判断片段最值得研究的地方；
2. 与既有样本交叉比较；
3. 移入合适的作者 / 作品目录；
4. 把中间观察写入 `references/storytelling/notes/`；
5. 只有稳定规律才更新 `skills/fiction-writing/SKILL.md`。

对于仍受版权保护的作品，不要把整本或大量连续章节提交到公开仓库。长材料优先保存来源、章节、链接和有限的必要片段。
