# Storytelling Analysis Notes

这里保存跨样本的中间分析。它们比单个样本更抽象，但尚未达到 `SKILL.md` 的稳定程度。

建议逐步形成以下专题：

- `dialogue.md`：对白、沉默、潜台词、话题中断；
- `ordinary-life.md`：没有大事件时怎样保持可读性；
- `pacing.md`：时间跳跃、场景切换、快慢控制；
- `character-entry.md`：人物第一次出现如何立住；
- `information-release.md`：信息给与不给；
- `combat.md`：打斗的动作选择、视角、结果力度；
- `humor.md`：人物逻辑产生的冷幽默；
- `anti-ai-patterns.md`：monster-flick 已实际踩过的 AI 写作陷阱。

## 提升规则

一个观察不要因为单个喜欢的片段就直接写进 Skill。

优先满足至少一种条件：

1. 在多个不同样本中反复出现；
2. 与用户明确的阅读直觉一致；
3. 在 `monster-flick` 实际正文试写中验证有效；
4. 能明确解释既有失败稿为什么失败。

Skill 的目标不是制造固定文风，而是让正文更像真实人物在真实环境里发生事情。
